### 경로 비교

| 경로 | 길이(주) | 임계 여부 |
|------|----------|-----------|
| 1.1 → 2.0 → 3.2 → 4.2 → 5.1 → 5.3 → 6.1 | 1 + 4 + 3 + 5 + 4 + 2 + 1 = **20** | 임계 |
| 1.1 → 2.0 → 3.2 → 4.1 → 5.1 → 5.3 → 6.1 | 1 + 4 + 3 + 4 + 4 + 2 + 1 = 19 | 여유 1 |
| 1.1 → 2.0 → 3.2 → 4.3 → 5.1 → 5.3 → 6.1 | 19 | 여유 1 |
| 1.1 → 2.0 → 3.1 → 4.1 → 5.1 → 5.3 → 6.1 | 1 + 4 + 2 + 4 + 4 + 2 + 1 = 18 | 여유 2 |
| 1.1 → 2.0 → 3.2 → 4.5 → 5.1 → 5.3 → 6.1 | 17 | 여유 3 |

임계 경로: **1.1 착수 → 2.0 요구분석 → 3.2 DB 설계 → 4.2 성적 모듈 → 5.1 통합 테스트 → 5.3 인수 → 6.1 가동 준비**, 길이 20주
가용 기간 대비: 임계 20주 + 예비 2주 = 22주 ≤ 가용 22주 → **통과** (예비는 임계 경로의 10%)

임계 경로 위 활동(요구분석, DB 설계, 성적 모듈, 통합 테스트)은 1주라도 늦어지면 예비를 소모한다. 학적·수강신청 모듈은 1주, 화면 설계는 2주 늦어도 가동일에 영향이 없다. 이 네 활동을 `sw-sqa` 주간 검토의 고정 점검 항목으로 둔다.

### 완료 확률 (PERT)

임계 경로 PERT 활동 분산: 2.0 (0.67²) + 3.2 (0.50²) + 4.2 (0.67²) + 5.1 (0.50²) = 0.44 + 0.25 + 0.44 + 0.25 = 1.38 → σ = 1.18주
PERT 기대 길이 = 1 + 4.33 + 3.17 + 5.33 + 4.17 + 2 + 1 = 21.0주
목표 22주: Z = (22 − 21.0) ÷ 1.18 = 0.85 → 완료 확률 약 **80%**
예비 없이 20주 목표였다면 Z = −0.85 → 20%. 예비 2주가 필수인 이유다.
