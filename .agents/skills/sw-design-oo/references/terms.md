# 용어 대조표 (sw-design-oo)

강의에서 쓰인 암기법·별칭과 이 스킬에서 쓰는 정식 용어의 대조표다. 본문에는 정식 용어만 쓴다.

| 강의 표현 | 정식 용어 | 뜻 |
|-----------|-----------|----|
| 객체는 동기다 | 객체 모델 → 동적 모델 → 기능 모델 | 럼바우 분석 3모델과 순서 |
| 계분설구 | 계획 → 분석 → 설계 → 구현 | 객체지향 생명주기. 분석·설계·구현에서 같은 객체 개념 사용 |
| 붕어빵틀 / 붕어빵 | 클래스 / 객체(인스턴스) | 틀과 그 틀로 만든 실체 |
| 붕어빵 찍기 | 인스턴스화(Instantiation) | `new` |
| 민증까(), 구구단외우기() | 메소드(Method) | 객체의 연산 |
| 대한민국 → 한사대 | 상위 클래스 → 하위 클래스 (`extends`) | 상속 예 |
| 감기약 캡슐 | 캡슐화 / 정보 은닉 | 안을 몰라도 쓸 수 있음 |
| 운동경기 ← 축구·야구·배구 | 추상화 (추상 클래스) | 공통 성질을 상위로 |
| 공격하다() 가 종목마다 다름 | 다형성 (오버라이딩) | 같은 메시지, 다른 동작 |
| 응 high 결 low | 응집도 높게, 결합도 낮게 | 패키지 설계 기준 |
| OMT | 럼바우 기법(Object Modeling Technique) | UML의 뿌리 |
| 사건 추적도 | 시퀀스 다이어그램의 원형(Event Trace) | 객체 간 메시지 순서 |
| OOA / OOD / OOP / OOT | 객체지향 분석 / 설계 / 프로그래밍 / 테스트 | |
| OMG | Object Management Group | UML 표준화 기구 |
| 클래스 테스트 | 단위 테스트 | 객체지향에서 단위 = 클래스 |

## 럼바우 3모델 요약

| 모델 | 보는 것 | 산출물 |
|------|---------|--------|
| 객체 | 구조 | 클래스 다이어그램 |
| 동적 | 시간 | 상태도, 시퀀스 |
| 기능 | 변환 | DFD |

## 4대 원리 요약

| 원리 | 본질 | Java |
|------|------|------|
| 캡슐화 | 보호·은닉 | private + public 메소드 |
| 추상화 | 단순화·공통화 | abstract, interface |
| 상속 | 재사용·확장 | extends |
| 다형성 | 행동 다양화 | @Override |

## UML 5종 요약

| 다이어그램 | 정적/동적 | 핵심 |
|-----------|----------|------|
| 유스케이스 | 기능 | 액터·유스케이스·관계 (객체 없음) |
| 클래스 | 정적 | 구조의 뼈대 |
| 시퀀스 | 동적 | 메시지 순서 |
| 상태 | 동적 | 한 객체의 생애 |
| 활동 | 동적 | 처리 흐름 |

## 객체지향 테스트 순서

단위(클래스) → 통합(스레드 기반 / 사용 기반) → 검증 → 시스템
