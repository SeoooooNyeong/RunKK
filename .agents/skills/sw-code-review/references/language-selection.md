# 프로그래밍 언어 선정 기준과 세대

언어는 취향이 아니라 문제와 환경에 맞춰 고른다. 최초 리뷰에서 한 번 평가해 기록을 남기고, 유지보수 단계에서 "왜 이 언어였는가"를 물을 때 참조한다.

## 1. 저급 언어와 고급 언어

| 구분 | 특징 | 예 | 언제 쓰는가 |
|------|------|----|-------------|
| 저급 언어 | 기계에 가까움. 하드웨어 직접 제어. 이식성 낮음 | 기계어, 어셈블리어 | 장치 드라이버, 극한 성능 구간 |
| 고급 언어 | 사람이 읽고 쓰기 쉬움. 하드웨어 구조를 몰라도 됨 | C, C++, Java, Python, SQL | 대부분의 응용 소프트웨어 |

## 2. 언어 세대

| 세대 | 특징 | 예 |
|------|------|----|
| 1세대 | 기계어. 0과 1 | 기계어 |
| 2세대 | 기호화된 기계어 | 어셈블리어 (MOV, ADD) |
| 3세대 | 절차적 고급 언어. "어떻게" 할지를 기술 | C, C++, Java, Fortran, COBOL |
| 4세대 | 비절차적 언어. "무엇을" 할지만 선언하고 방법은 언어가 처리 | SQL, 보고서 생성 언어 |

4세대 언어는 생산성이 높지만 적용 영역이 좁다. 4세대 기법(4GT) 모형은 CASE 도구와 4세대 언어로 명세에서 코드를 자동 생성하는 접근이며, 중소형 프로젝트에서 효과가 크고 대규모에서는 분석·설계가 오히려 길어질 수 있다.

## 3. 선정 기준 9개

각 기준에 **적합 / 보통 / 부적합** 을 매긴다.

| 번호 | 기준 | 판정 질문 |
|------|------|-----------|
| 1 | 친숙성 | 팀원 과반이 이 언어로 1년 이상 개발한 경험이 있는가 |
| 2 | 사용 능력 | 이 언어가 문제 해결에 필요한 기능(동시성, 수치 연산, 문자열 처리 등)을 갖추었는가 |
| 3 | 처리 효율성 | 응답 시간·메모리 요구(SRS의 비기능 요구)를 이 언어의 실행 특성으로 만족할 수 있는가 |
| 4 | 과거 개발 실적 | 연동하거나 확장할 기존 시스템이 같은 언어인가 |
| 5 | 문제 유형 | 공학·과학 계산, 사무 처리, 실시간 제어, 웹 중 어느 유형이며 그 유형에 흔히 쓰이는 언어인가 |
| 6 | 자료 구조 | 필요한 자료 구조(그래프, 대용량 행렬, 트리)를 표준 라이브러리로 지원하는가 |
| 7 | 이식성 | 목표 환경(Windows, Linux, 모바일) 모두에서 동작하는가 |
| 8 | 개발자 경험 | 팀에 이 언어의 고급 기능과 함정을 아는 사람이 있는가 (1번과 구분: 1번은 분포, 8번은 깊이) |
| 9 | 컴파일러·도구 | 컴파일러, 디버거, 빌드 도구, 패키지 생태계를 쓸 수 있는가 |

선정 기준이 **아닌** 것: "4세대 언어인가", "최신 언어인가", "개발자가 배우고 싶은 언어인가". 이런 이유가 선정 근거로 제시되면 기준표에서 제외하고 기록만 남긴다.

## 4. 평가 양식

```
언어: Java 17
| 기준 | 판정 | 근거 |
| 친숙성 | 적합 | 5명 중 4명 Java 3년 이상 |
| 사용 능력 | 적합 | 트랜잭션·동시성 라이브러리 충분 |
| 처리 효율성 | 적합 | 응답 2초 요구 대비 여유 |
| 과거 개발 실적 | 적합 | 기존 학적 DB 연동 모듈이 Java |
| 문제 유형 | 적합 | 사무 처리형 |
| 자료 구조 | 적합 | 표준 컬렉션으로 충분 |
| 이식성 | 적합 | JVM |
| 개발자 경험 | 보통 | 동시성 고급 기능 경험자 1명 |
| 컴파일러·도구 | 적합 | Maven, IDE |
부적합 0건 → 재검토 불필요
```

부적합 3건 이상이면 "언어 재검토 권고"를 남기되 코드 리뷰 판정에는 반영하지 않는다.

## 5. 용어 대조

| 강의 표현 | 이 문서 |
|-----------|---------|
| 친숙성(Familiarity) | 기준 1 |
| 사용 능력 | 기준 2 |
| 처리 효율성 | 기준 3 |
| 과거 개발 실적 | 기준 4 |
| 문제 유형 | 기준 5 |
| 자료구조 난이도, 성능 고려 | 기준 6, 3 |
| 이식성(Portability) | 기준 7 |
| 개발자의 경험, 컴파일러 이용 가능 여부 | 기준 8, 9 |
| "4세대 언어인지 여부"는 선정 기준과 무관 | 3절 마지막 단락 |
