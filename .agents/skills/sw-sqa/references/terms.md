# 용어 대조표 (sw-sqa)

강의에서 쓰는 표현과 이 스킬의 용어를 대조한다. 본문에서는 왼쪽 표현을 쓰지 않는다.

## 품질

| 강의 표현 | 스킬 용어 |
|-----------|-----------|
| 설계 품질(Design Quality) / 일치 품질(Conformance Quality) | 품질의 두 측면 |
| 품질 관리(Quality Control) | 전 산출물에 대한 품질 기준 관리 |
| 품질 표준 10가지 (실제 11개) | 품질 속성 11개 (`quality-attributes.md`) |
| 신정효이사 | 신뢰성·정확성·효율성·이식성·사용 용이성 |
| 품질 보증 4조건: 요구 충족, 성능, 예산·기간, 유연성 | `quality-attributes.md` 마지막 절 |
| 개발자 관점 품질 측정에서 거리가 먼 것: 간결성 | 간결성은 11개 속성에 없음. 코딩 스타일 항목 |

## 검토

| 강의 표현 | 스킬 용어 |
|-----------|-----------|
| SQA = 전 개발 단계에 걸친 계획적·체계적 품질 활동 | 품질 보증 |
| 초기·중간·마지막 | SQA 3시점 (`review-types.md` 2절) |
| 정형 기술 검토, FTR | FTR (`ftr-checklist.md`) |
| FTR 기본 지침 6개 | 지침 1~6 |
| Walkthrough / 구조적 Walkthrough / Inspection | 워크스루 / 구조적 워크스루 / 인스펙션 |
| Verification / Validation / Certification / Test / Debugging | 검증 / 확인 / 인증 / 시험 / 디버깅 |

## 위험

| 강의 표현 | 스킬 용어 |
|-----------|-----------|
| 위험 관리 = 돌발 상황 예측과 대책 | 위험 관리 (`risk-management.md`) |
| 프로젝트 / 기술적 / 비즈니스 위험 | 위험 세 종류 |
| Charette: Known / Predictable / Unpredictable | 알려진 / 예측 가능 / 예측 불가 |
| 식별 → 분석 및 평가 → 계획 → 감시 및 조치 | 절차 4단계 (순서 고정) |
| Risk Table: 내용·종류·확률·영향 (발생 시간은 제외) | 위험 표. 발생 시간 열 없음 |
| 회피(Avoid) / 감시(Monitor) / 비상 계획(Contingency Plan) | 대응 전략. 선호 순서 회피 > 감시 > 비상 |
| 위험 모니터링 = 징후를 계속적으로 인지 | 감시 |
| 대표 위험 요소 = 사용자 요구사항 변경 | 동일 |
| 위험 요소로 거리가 먼 것 = 유지보수 | 위험 목록 제외 항목 |
| 위험 분석 대상이 아닌 것 = 사용자 자체의 위험성 | 위험 목록 제외 항목 |

## 프로젝트 관리와의 관계

| 강의 표현 | 스킬 용어 |
|-----------|-----------|
| 프로젝트 관리 대상: 계획·비용·일정·조직·품질·위험 (고객 관리는 제외) | 품질 관리와 위험 관리는 `sw-plan`이 계획하고 `sw-sqa`가 점검 |
| 3P: People, Problem, Process | `sw-plan` 참조 |
