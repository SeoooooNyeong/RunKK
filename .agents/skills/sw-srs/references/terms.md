# 용어 대조표 (sw-srs)

강의에서 쓰인 암기법·별칭과 이 스킬에서 쓰는 정식 용어의 대조표다. 본문에는 정식 용어만 쓴다.

| 강의 표현 | 정식 용어 | 뜻 |
|-----------|-----------|----|
| 도분명확 | 도출 → 분석 → 명세화 → 확인 | 요구사항 개발 4단계 |
| 계분설구(테유) | 계획 → 분석 → 설계 → 구현 → 테스트 → 유지보수 | 생명주기 단계. 이 스킬은 "분석" |
| 버블 | 프로세스(Process) | DFD의 원 |
| 단말, 외부 개체 | 단말(Terminator) / 외부 개체(External Entity) | DFD의 사각형. 같은 뜻 |
| 배경도, 기본 시스템 모델 | 배경도(Context Diagram), Level 0 | 시스템 전체를 원 하나로 |
| 자료사전, DD | 자료사전(Data Dictionary) | DFD 자료의 정의서. 메타데이터 |
| 소단위 명세서, Mini-spec | 소단위 명세서(Mini-specification) | 최하위 프로세스의 처리 논리 |
| 스펙 문서 | 요구사항 명세서(SRS, Software Requirements Specification) | 분석 단계 산출물 |
| 원형 모형, 시제품 모형 | 프로토타입 모형(Prototyping Model) | 시제품으로 요구를 확인하는 생명주기 모형 |
| What / How | 분석은 무엇을(What), 설계는 어떻게(How) | 단계 경계 |
| 기준선 | 기준선(Baseline) | 승인된 버전. 이후 변경 통제 대상 |

## 자료사전 기호 요약

| 기호 | 뜻 |
|------|----|
| `=` | 구성되어 있다 |
| `+` | 그리고(연결) |
| `{ }` | 반복 |
| `( )` | 생략 가능 |
| `[ \| ]` | 선택 |
| `* *` | 주석 |

## DFD 도형 요약

| 도형 | 요소 |
|------|------|
| 원 | 프로세스 |
| 화살표 | 자료 흐름 |
| 평행선 | 자료 저장소 |
| 사각형 | 단말 |
