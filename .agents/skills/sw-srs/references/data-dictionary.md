# 자료사전(Data Dictionary) 작성법

`sw-srs` 4단계에서 읽는다. 자료사전은 DFD에 나오는 모든 자료의 **정의서**다. "자료에 관한 자료", 즉 메타데이터다. DFD가 "성적입력"이라는 화살표를 보여 주면, 자료사전은 "성적입력 안에 무엇이 들어 있는가"를 답한다.

## 1. 표기 기호

| 기호 | 뜻 | 읽는 법 | 예 |
|------|----|---------|-----|
| `=` | 구성 | ~는 다음으로 구성된다 | `성적입력 = 학번 + 과목코드 + 점수` |
| `+` | 연결(AND) | 그리고 | `학번 + 성명` |
| `{ }` | 반복 | 0회 이상(또는 n회) 반복 | `{과목코드 + 점수}`, `3{과목코드}8` (3~8회) |
| `( )` | 생략 가능 | 있을 수도 없을 수도 | `(비고)` |
| `[ \| ]` | 선택(OR) | 둘 중 하나 | `[현금 \| 카드 \| 계좌이체]` |
| `* *` | 주석 | 설명 | `* 0~100 정수 *` |

선택 기호는 `[ ]` 안에 `|`로 나열하는 표기와 `|`만 쓰는 표기가 모두 쓰인다. 한 문서 안에서는 하나로 통일한다. 이 저장소는 `[a | b | c]`를 쓴다.

## 2. 항목 구성

항목 하나는 **정의**와 **설명** 두 부분으로 쓴다.

```
성적입력 = 학번 + 과목코드 + 점수 + (비고)
    * 교수가 성적 입력 화면에서 보내는 자료. 점수는 0~100 정수. 비고는 결시·부정행위 사유 *
```

설명에는 출처(어느 단말·프로세스에서 나오는가), 값의 범위·형식, 업무 의미를 쓴다.

## 3. 작성 규칙

1. **이름 중복 금지.** 같은 이름이 두 번 정의되면 어느 것이 맞는지 알 수 없다. 비슷하지만 다른 자료는 이름도 다르게 한다("성적입력"과 "검증된 성적").
2. **DFD와 이름이 같아야 한다.** DFD의 모든 흐름·저장소 이름을 자료사전 항목으로 옮긴다. 자료사전에만 있고 DFD에 없는 이름은 하위 요소(학번, 점수 등)여야 한다.
3. **하위 요소까지 내려간다.** `성적입력`을 정의했으면 `학번`, `과목코드`, `점수`도 기본 요소로 정의한다. 기본 요소는 형식과 범위를 쓴다: `학번 = * 10자리 숫자, 입학년도 4자리 + 일련번호 6자리 *`.
4. **갱신하기 쉽게.** 한 항목이 한 블록을 넘지 않는다. 긴 구조는 중간 이름을 만들어 나눈다.
5. **정의 방식을 통일한다.** 한 문서 안에서 반복 횟수 표기(`{ }` vs `3{ }8`), 선택 표기를 섞지 않는다.
6. **찾기 쉽게.** 가나다순 또는 DFD 등장 순서 중 하나로 정렬한다. 긴 문서는 가나다순이 낫다.

## 4. 저장소 정의

자료 저장소도 자료사전에 정의한다. 저장소는 보통 레코드의 반복이다.

```
성적 DB = {성적레코드}
성적레코드 = 학번 + 과목코드 + 학기 + 점수 + 등급 + 입력일시 + (수정일시)
```

ERD를 그렸다면 저장소 정의와 ERD의 개체가 일치해야 한다.

## 5. 역할

| 역할 | 설명 |
|------|------|
| 자료 정의 | DFD의 각 자료가 어떤 요소로 되어 있는지 확정 |
| 일관성 | 분석가·개발자·사용자가 같은 이름을 같은 뜻으로 씀 |
| 변경 용이 | 구조가 적혀 있으니 바뀔 때 영향 범위를 바로 찾음 |
| 검색 용이 | 이름으로 정의를 찾을 수 있음 |
| 설계 입력 | 데이터 설계(ERD, 테이블, 클래스 속성)의 출발점 |

## 6. 학사관리 시스템 예

```
학생등록정보 = 학번 + 성명 + 학과코드 + 입학년도 + 연락처 + (보호자연락처)
학번         = * 10자리 숫자. 입학년도 4자리 + 일련번호 6자리 *
성적입력     = 학번 + 과목코드 + 학기 + 점수 + (비고)
점수         = * 0~100 정수. 결시는 비고에 사유를 쓰고 0 *
검증된 성적  = 성적입력 + 등급
등급         = [A+ | A | B+ | B | C+ | C | D+ | D | F]
성적표       = 학번 + 성명 + 학기 + {과목코드 + 과목명 + 학점 + 등급} + 평점평균
수강신청     = 학번 + 학기 + {과목코드}
신청결과     = 학번 + 학기 + {과목코드 + 상태}
상태         = [확정 | 승인대기 | 반려]
이의신청     = 학번 + 과목코드 + 학기 + 사유 + 신청일시
```
