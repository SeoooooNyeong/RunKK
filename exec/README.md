# exec: 포팅·제출 자료

SSAFY 제출 규칙에 맞춰 런크크(S15P31A207)를 다른 사람이 빌드·배포·시연할 때 필요한 자료를 모은 폴더다. 내용은 main 브랜치 코드와 설정 파일을 읽고 썼다(작성 2026-11-18, 앱 versionName 0.13.0, 운영 DB Flyway V67).

| 파일 | 내용 |
|---|---|
| [1_포팅_매뉴얼.md](1_포팅_매뉴얼.md) | 시스템 구성, 사용 제품과 버전, 빌드·실행·배포 방법, 환경 변수 이름, 배포 특이사항, DB 접속 방법, 설정 파일 위치 |
| [2_외부_서비스.md](2_외부_서비스.md) | 코드가 쓰는 외부 서비스(카카오, Google, Firebase, GMS, Anthropic, 기상청 등)와 콘솔에서 할 일 |
| [3_DB_덤프/](3_DB_덤프/) | 운영 DB 스키마 덤프(`runkk_schema.sql`, 데이터 없음)와 설명 |
| [4_시연_시나리오.md](4_시연_시나리오.md) | 앱 화면 흐름 기준 시연 순서와 기대 화면 |

## 지킨 것

- 비밀값(비밀번호, 키, 토큰, 키스토어)은 어느 파일에도 쓰지 않았다. 환경 변수는 이름과 용도만 적었고, 값은 팀에서 따로 전달한다.
- DB 덤프는 구조만 담았다. 회원 자료는 개인정보라 넣지 않았다.
- 저장소 안의 원본 문서가 더 자세하다. 서버 운영은 `infra/README.md`, 산출물 문서는 `docs/sw/README.md`를 본다.
- 근거를 찾지 못한 내용은 "확인 필요"로 표시했다.
