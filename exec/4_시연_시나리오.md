# 런크크 시연 시나리오

> 기준: main 브랜치 앱(versionName 0.13.0)과 `docs/sw/srs/05-외부-인터페이스.md`(화면 목록), `docs/sw/srs/03-*.md`(기능 요구), 앱 문구(`android/**/res/values/strings.xml`). 화면·단추 이름은 앱에 보이는 그대로 적었다.
> 하단 탭은 왼쪽부터 **크루 · 기록런 · 홈 · 랭킹 · 마이** 다섯 개다.

## 0. 준비

| 항목 | 내용 |
|---|---|
| 기기 | Android 폰 2대(대결·크루런 상대용), Wear OS 워치 1대(폰과 페어링). 폰은 Android 8.0(API 26) 이상, 워치는 Wear OS API 30 이상 |
| 앱 | 운영 서버 시연은 prod 앱(`com.a207.runkk`, Play 비공개 테스트 또는 베타 APK). 개발 서버 시연은 develop APK(`com.a207.runkk.dev`, 8443) |
| 시연 데이터 | 개발 서버는 CI `dev:seed`로 더미 러너 18명, 공개 크루 5개(`더미 …`)와 러닝 기록을 넣어 둘 수 있다. 운영 서버에는 더미 데이터를 넣지 않는다 |
| 서버 스위치 | 크루 `CREW_RELEASED`, 아바타 `AVATAR_RELEASED`, 런바디 `RUNBODY_ENABLED`, AI 코치 `COACH_ENABLED`가 관리툴 운영 기준값에서 켜져 있어야 한다. 셀카 아바타는 서버 `SELFIE_ENABLED=true`도 필요하다. 2026-11-18 기준 운영·개발 서버 모두 네 스위치와 `SELFIE_ENABLED`가 켜져 있다(개발 서버 AI 코치는 이날 켬) |
| 계정 | 시연용 카카오 계정. 대결·크루런 상대 폰은 다른 계정으로 로그인 |
| 권한 | 위치(정확한 위치), 알림, 카메라(셀카), 워치 심박(선택) |
| 시간 | 셀카 아바타 생성은 한 건에 1분 안팎 걸린다. 크루런 대기실은 시작 30분 전부터 열린다. 미리 크루런 일정을 만들어 둔다 |

## 1. 시작: 게스트 시작 또는 카카오 로그인

| 단계 | 조작 | 기대 화면 |
|---|---|---|
| 1-1 | 앱 실행 | 스플래시(런크크 워드마크) 뒤 로그인 화면. 배경 영상과 로그인 음악 |
| 1-2 | **카카오톡으로 시작하기** (또는 **구글 계정으로 시작하기**) | 카카오 인증 뒤 가입 동의 화면: 전체 동의, 필수 동의 3종, 만 14세 이상 확인, 선택 동의 |
| 1-2' | 다른 길: **게스트로 시작하기** | 동의 뒤 「게스트로 시작했어요」 안내(자동 닉네임, 「지금 연동하기」·「나중에」). 게스트 자료는 기기를 바꾸면 사라진다는 고지 |
| 1-3 | 동의 후 진행 | 홈. 처음 한 번 첫 사용 가이드(「런크크가 처음이신가요?」, 건너뛰기·다음·시작하기) |

게스트는 나중에 마이 > 설정에서 **카카오 계정 연동**·**Google 계정 연동**으로 같은 기록을 이어 쓸 수 있다.

## 2. 홈과 아바타(셀카 아바타)

| 단계 | 조작 | 기대 화면 |
|---|---|---|
| 2-1 | 홈 둘러보기 | 닉네임·티어·레벨(Lv.), 리워드 잔액(P), 알림함, 이번 주 목표 거리 막대와 「n주 연속」, 내 아바타, **자유런** 카드, **배틀런** 카드(「랜덤 또는 친구와 대결」), 「내 기록 요약」, 러닝 잔디(최근 5주) |
| 2-2 | 아바타를 눌러 **내 러너** 열기 | 서 있는 내 아바타와 배경, 레벨, 이번 주 달린 횟수·거리, **얼굴**, **꾸미기** |
| 2-3 | **얼굴 만들기** 화면 → **셀카 찍기** | 「얼굴 변환 서비스 전송 (선택)」 동의 확인 뒤 카메라. 촬영 후 생성 중 화면. 들어가는 경로: 홈의 내 아바타 → 「내 러너」 → 「얼굴」 → 「얼굴 만들기」. 생성 중에는 홈 아바타 위 배지, 완료 뒤에는 결과 알림으로도 같은 화면이 열린다 |
| 2-4 | 생성 완료 기다리기(1분 안팎) | 「새 얼굴이 준비됐어요」. 셀카를 닮은 SD 얼굴(「셀카 SD 얼굴」)이 아바타에 붙는다. 앞모습·옆모습이 함께 만들어진다 |
| 2-5 | **꾸미기** | 옷·배경 바꾸기. 바꾼 모습이 홈과 랭킹에도 보인다 |

- 셀카 아바타는 하루에 한 번 만들 수 있다(「오늘은 이미 셀카 아바타를 만들었어요」). 실패는 하루 5번까지다. 시연 전 같은 계정으로 미리 만들지 않는다.
- 셀카 원본은 생성 뒤 지운다(서버 디스크에 남기지 않음).

## 3. 배틀런: 배치고사와 티어

| 단계 | 조작 | 기대 화면 |
|---|---|---|
| 3-1 | 홈 **배틀런** 카드 | 배틀런 진입 시트 「어떤 대결을 할까요?」: 랜덤 대결 카드(배치 중이면 「배치고사 n/3」), 친구 대결 카드 |
| 3-2 | 랜덤 대결 선택 | 배치 중이면 배치고사 진행 카드와 임시 티어 배지, 「배치고사 n판 시작」. 확정 티어가 있으면 내 아바타 VS 「?」, 거리 칩 1·3·5·10km, 내 최고 기록, 「n km 매칭 시작」 |
| 3-3 | 거리 1km 고르고 시작 | 매칭 대기. 15초 안에 실시간 상대가 없으면 실패 안내 없이 고스트(다른 러너 기록) 상대로 넘어간다. 두 번째 폰으로 같은 거리를 동시에 누르면 실시간 대결이 된다 |
| 3-4 | 매칭 성사 | 상대 정보와 10초 카운트다운 뒤 자동 출발 |
| 3-5 | 달리기 | 대결 진행 화면: 트랙 위 두 아바타, 상대와 거리 차, 추월 안내(음성·진동). 지도 보기로 바꿀 수 있다 |
| 3-6 | 목표 거리 도달 | 대결 결과: 승리·패배·무승부 큰 제목, 시간 차 |
| 3-7 | 배치고사 판 결과 | 「배치고사 결과」, 「다음 판 뛰기」. 3판을 마치면 「배치고사 완료」, 「○○ 티어가 됐어요」와 3판 표 |

- 배치고사 판은 그 대결의 러닝이 유효 러닝일 때만 센다. 승패는 상관없다.
- 친구 대결: 진입 시트에서 친구 대결 → 「누가 더 빠를지 친구와 대결해 볼까요?」 → 거리 선택 → **카카오톡으로 초대하기**. 받는 사람이 링크를 누르면 앱이 열려 참가 확인 화면으로 간다(앱이 없으면 Play 스토어 안내 페이지). 초대는 최대 5분 유효하다.

## 4. 기록런: 셀프런과 셀럽런

| 단계 | 조작 | 기대 화면 |
|---|---|---|
| 4-1 | 하단 **기록런** 탭 | **셀프런**과 **셀럽런**을 고르는 화면 |
| 4-2 | **셀프런** → 거리(1·3·5·10km·하프) | 내 지난 최고 기록과 대결 준비. 기록이 없으면 「아직 대결할 기록이 없어요」 |
| 4-3 | **셀럽런** → 거리 → 셀럽 카드 고르기 → **대결하기** | 셀럽 기록(가림 이름, 셀럽 캐릭터)과 대결. 거리에 셀럽 기록이 없으면 「이 거리의 셀럽 기록이 없어요」 |
| 4-4 | 달리기와 결과 | 배틀런과 같은 대결 진행 화면, 대결 결과. 셀프런·셀럽런은 「취소」와 그만두기가 따로 있다 |

## 5. 크루와 크루런

| 단계 | 조작 | 기대 화면 |
|---|---|---|
| 5-1 | 하단 **크루** 탭 | 크루 찾기: 「전체 크루」·「조건에 맞는 크루」, 「조건 설정하기」, 크루명 검색, 「초대 코드로 가입」 |
| 5-2 | 크루 고르고 가입 신청(또는 만들기) | 「가입 신청을 보냈어요」. 크루장이 받으면 내 크루 |
| 5-3 | 내 크루 **레이스** 탭 | 이번 주 크루 거리, 기여도, 공동 목표 진행률, 크루 내 랭킹 |
| 5-4 | **크루런** 탭 → **크루런 모집하기** | 일시·장소를 넣어 모집글을 만든다. 크루원은 참석·불참·미정으로 응답한다 |
| 5-5 | 시작 30분 전부터 **대기실 입장하기** | 크루런 대기실: 「준비 완료 n / m」. 각자 **준비 완료**를 누른다 |
| 5-6 | 출발 | 모두 준비 완료면 「모두 준비됐어요」와 함께 몇 초 뒤 출발한다. 「지금 시작」으로 바로 시작할 수도 있다. 진행 중 화면에 함께 달린 거리 합계가 보인다 |
| 5-7 | 종료 | 크루런 결과·결과 상세(순위 없이 함께 달린 거리 합산) |
| 5-8 | **채팅** 탭 | 크루 채팅. 메시지 보내기, 반응 달기 |

## 6. 런바디와 AI 코치

| 단계 | 조작 | 기대 화면 |
|---|---|---|
| 6-1 | 마이 → **런바디** | 런바디(러닝별·월간). 러닝을 저장한 뒤 분석이 끝나면 5각 점수, 판정, km 랩, 피드백 문장, 최근 10회 변화 |
| 6-2 | 분석 전이면 | 「분석을 준비하고 있어요」. 데이터가 모자라면 「분석할 데이터가 부족해요」 |
| 6-3 | 런바디의 **AI 코치** | 처음이면 「AI 코치 이용을 위한 동의 확인」(러닝 집계값과 질문 원문을 외부 LLM으로 보낸다는 안내) |
| 6-4 | 질문 입력(예: "다음 주에 5km 기록을 줄이려면?") | 내 기록을 바탕으로 한 답이 글자 단위로 이어서 나온다 |

- AI 코치는 하루 질문 수 상한이 있다(전체·사용자별). 동의하지 않아도 런바디의 규칙 기반 코멘트는 볼 수 있다.

## 7. 기록 상세와 카드 공유

| 단계 | 조작 | 기대 화면 |
|---|---|---|
| 7-1 | 자유런 한 번 마치기(홈 **자유런** → 카운트다운 → 측정 → 종료) | 러닝 결과: 거리 → 지표 카드 → 구간 페이스 → 심박 구간 순서. 기록 카드 팝업(「공유」·「닫기」) |
| 7-2 | 홈 「기록 상세 보기」 또는 마이 → **러닝 기록** | 기록(달력·목록·대결 탭) → **기록 상세**: 코스 지도(카카오맵), 페이스, 심박, 날씨 |
| 7-3 | **러닝 카드 공유** | 카드 앞면 그림으로 시스템 공유 창. 카카오톡·메신저 등으로 보낸다 |
| 7-4 | 마이 → **성장 분석** | 거리별 최고 기록 등 성장 지표 |

## 8. 상점

| 단계 | 조작 | 기대 화면 |
|---|---|---|
| 8-1 | 홈 리워드 잔액(P) 옆 「상점 열기」 또는 꾸미기의 「상점에서 더 보기」 | **상점**: 옷·배경 아이템과 가격(P). 잠긴 아이템은 조건이 표시된다 |
| 8-2 | 아이템 고르기 → 「… 살까요?」 확인 | 포인트가 줄고 아이템이 꾸미기 목록에 들어간다 |
| 8-3 | 꾸미기에서 입히기 | 내 러너 아바타에 바로 보인다 |

## 9. 워치

| 단계 | 조작 | 기대 화면 |
|---|---|---|
| 9-1 | 폰에서 로그인한 상태로 워치 앱 실행 | 워치 메인: 모드 캐러셀(자유런, 배틀런, 셀프런, 셀럽런). 베젤이나 밀기로 넘긴다. 폰이 로그인 전이면 「폰에서 런크크에 로그인해 주세요」 |
| 9-2 | 자유런 → 목표 거리(무제한, 3·5·10km) → 달리기 시작 | 카운트다운 뒤 측정 화면(시간·거리·페이스·심박). 시계 화면에 진행 중 활동 표시 |
| 9-3 | 길게 눌러 종료 | 워치 결과. 기록은 폰으로 넘어가 저장된다 |
| 9-4 | 폰에서 배틀런 시작 | 워치에 동행 표시 화면. 상대와 가까워지면 비프음·진동 근접 알림 |

## 10. 마무리로 보여 줄 것(선택)

- 하단 **랭킹** 탭: 1~3위 시상대(서 있는 아바타), 4위부터 목록, 누적 유효 거리.
- 알림함 → **이벤트**: 진행 중인 이벤트 목록과 상세.
- 마이 → **목표와 러닝 코치**: 「오늘 계획 정하기」(거리 3·5·7·10km, 목표 페이스).
