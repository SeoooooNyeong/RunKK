# 용어 대조표 (sw-plan)

강의에서 쓰인 암기법과 약어를 본문 용어와 대조한다. 본문(SKILL.md, 산출물)에는 암기법을 쓰지 않는다.

| 강의 표현 | 본문 용어 | 의미 |
|-----------|-----------|------|
| 계분설구(테유), 닭똥설구 | 생명주기 6단계 | 계획 → 분석 → 설계 → 구현 → 테스트 → 유지보수 |
| 3P, "사람이 문제를 처리한다" | 프로젝트 관리 3요소 | People(사람), Problem(문제), Process(프로세스) |
| "인사가 만사" | 조직 관리 | 인적 자원이 가장 중요한 자원 |
| "뭐니 뭐니 해도 머니" | 비용 관리 | 비용이 가장 중요한 관리 대상 |
| RFP | 제안요청서(Request for Proposal) | 발주처가 "이런 소프트웨어를 만들어 달라"고 요구하는 문서 |
| Proposal | 제안서 | 개발사가 RFP에 답해 "이렇게 만들겠다"고 제출하는 문서 |
| Scope | 범위 | 기능·성능·제약·인터페이스·신뢰도 5요소 |
| Milestone | 이정표 | 기간과 마감 기한의 중간 목표 |
| 신정효이사 | 품질 목표 5개 | 신뢰성, 정확성, 효율성, 이식성, 사용성 |
| Known / Predictable / Unpredictable | Charette 위험 분류 | 알려진 / 예측 가능한 / 예측 불가능한 위험 |
| Avoid / Monitor / Contingency | 위험 대응 전략 | 회피 / 감시 / 비상 계획 |
| Risk Table | 위험표 | 내용·범주·확률·영향·대응 (발생 시간 없음) |
| Customized / Commercial | 주문형 / 상업용 | 고객 발주 / 개발사 자체 개발 후 판매 |
| Task Framework | 업무 흐름 | 3P 중 프로세스에 해당 |
