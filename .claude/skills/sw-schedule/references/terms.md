# 용어 대조표 (sw-schedule)

강의의 암기 표현·약어와 본문 용어를 대조한다. 본문에는 암기법을 쓰지 않는다.

| 강의 표현 | 본문 용어 | 의미 |
|-----------|-----------|------|
| WBS | 작업 분해 구조(Work Breakdown Structure) | 프로젝트를 관리 가능한 작은 작업으로 계층 분해 |
| PERT | Program Evaluation and Review Technique | 3점 추정으로 불확실한 작업 기간을 예측하는 네트워크 기법 |
| CPM | Critical Path Method | 확정 기간으로 임계 경로를 찾는 네트워크 기법 |
| Critical Path | 임계 경로 | 가장 오래 걸리는 경로. 지연되면 전체가 지연 |
| "샤워기 온수 손잡이" | 임계(Critical)의 의미 | 조금만 움직여도 전체가 바뀌는 민감한 지점 |
| (O + 4M + P) ÷ 6 | PERT 기대 기간 | 낙관·기대·비관 가중 평균. LOC 3점 추정과 같은 형태 |
| 낙관치 / 기대치 / 비관치 | O(Optimistic) / M(Most likely) / P(Pessimistic) | |
| Slack | 여유 시간 | LS − ES. 임계 경로 활동은 0 |
| Node / Arrow | 노드 / 간선 | 활동 / 선후 관계 |
| Milestone | 이정표 | 기간 0인 중간 목표. 선행 활동이 모두 끝나야 도달 |
| Gantt Chart, Time-line Chart | 간트 차트 | 막대 = 기간. 의존 관계 표시 불가 |
| PM / MM | 인월 (Person-Month / Man-Month) | 작업량 단위. 기간 아님 |
| 40-20-40 | 노력 배분 기준 | 분석·설계 40, 코딩 20, 테스트·디버깅 40 |
| Brooks의 법칙 | 말기 인력 투입 금지 | 늦은 프로젝트에 인력을 더하면 더 늦어진다 |
| "삼계탕 끓이기" | WBS 예시 | 닭·재료·기구·조리를 가족이 분담 (책임 소재 명확화) |
| Democratic Team | 분산형 팀 | 링 구조, 경로 n(n−1)/2 |
| Chief Programmer Team | 중앙집중형 팀 | 책임 프로그래머 1인 결정. 역할 4개 |
| Hierarchical Team | 계층형 팀 | 5~7명 소그룹 + 고급 관리자 + 리더 |
| 프로그램 사서 | Program Librarian | 문서·형상 관리 담당 |
| Fast tracking / Crashing | 병행화 / 자원 추가 | 임계 경로 압축 방법 |
