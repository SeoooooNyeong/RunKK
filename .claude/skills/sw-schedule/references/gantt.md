# 간트 차트 작성 규칙

`sw-schedule` 절차 4·5에서 읽는다.

## 1. 정의

프로젝트 일정표를 막대그래프로 표현한 것. 시간선(Time-line) 차트라고도 한다. 각 활동이 언제 시작하고 언제 끝나는지, 즉 **기간**을 한눈에 보여 준다.

## 2. 구성 요소

| 요소 | 표현 | 의미 |
|------|------|------|
| 활동(Task) | 세로축 행 | WBS의 활동. 코드와 이름 |
| 기간(Duration) | 가로 막대 길이 | 시작 ~ 종료. **막대 길이는 기간이지 인원 수가 아니다** |
| 이정표(Milestone) | ◆ 점 | 기간 0인 중간 목표 |
| 산출물(Deliverable) | 행 끝 열 | 활동 종료 시 나오는 결과물 |
| 진척 | 막대 안 채움 | 실행 단계에서 갱신 |

## 3. 할 수 있는 것과 없는 것

| 할 수 있다 | 할 수 없다 |
|-----------|-----------|
| 시작·종료 시점 파악 | 활동 간 **의존 관계** 표시 |
| 지연 시 이유와 기간 예측 | **임계 경로** 식별 |
| 자원 배치·인원 계획 | 계획 변경 시 자동 반영 (수정이 번거롭다) |
| 예산 초과 구간 파악 | 담당자 주관 배제 |
| 전체를 시각적으로 조망 | |

그래서 순서는 WBS → 네트워크(PERT/CPM) → 간트다. 네트워크에서 계산한 ES·EF로 막대를 그리고, 임계 경로 활동은 표시를 달리한다. 간트만 보고 "이 활동은 늦어도 된다"고 판단하지 않는다.

## 4. 마크다운 표 형식

주 단위 열을 쓴다. 임계 경로 활동은 `█`, 그 외는 `▓`, 여유 구간은 `░`, 이정표는 `◆`.

```
| 코드 | 활동 | 담당 | W1 | W2 | W3 | W4 | W5 | W6 | 산출물 |
|------|------|------|----|----|----|----|----|----|--------|
| 1.0 | 착수 | PM | █ | | | | | | 착수 보고 |
| 2.0 | 요구분석 | 분석가 | | █ | █ | █ | █ | | srs.md |
| M1 | SRS 승인 | | | | | | ◆ | | |
| 3.1 | UI 설계 | 설계자 | | | | | | ▓ | 화면 설계서 |
```

열이 많아지면 월 단위로 묶은 요약 간트를 위에 두고 주 단위 상세를 아래에 둔다.

## 5. 월별 투입 인원표

간트 아래에 주(또는 월)별 투입 인원을 적는다. 이 표로 다음을 점검한다.

| 점검 | 기준 |
|------|------|
| 상한 | 어느 주도 확정 인원을 넘지 않는다 |
| 합계 | 전체 합 = 산정서 확정 노력(PM) |
| Brooks 법칙 | 테스트 단계 이후 인원이 전 단계보다 늘지 않는다 |
| 인력 곡선 | 초반 적음 → 중반 최대 → 후반 감소가 자연스럽다 (Rayleigh-Norden) |

## 6. 40-20-40 점검표

| 구간 | 포함 활동 | 인월 | 비율 | 기준 |
|------|-----------|------|------|------|
| 분석·설계 | 요구분석, 아키텍처·UI·DB 설계, 설계 검증 | | | 40% |
| 구현 | 코딩 (단위 테스트 제외) | | | 20% |
| 테스트·디버깅 | 단위·통합·부하·인수 테스트, 결함 수정 | | | 40% |

구현 활동 안에서 단위 테스트에 쓰는 시간은 테스트 구간으로 옮겨 센다. 그래야 비율이 바르게 나온다.

## 7. 이정표 선정 기준

- 단계 산출물이 승인되는 시점 (SRS 승인, 설계 승인)
- 외부 의존이 해소되는 시점 (기존 DB 스키마 수령)
- 발주처 평가가 있는 시점 (프로토타입 평가, 인수 테스트)
- 임계 경로의 분기·합류 지점

이정표는 5 ~ 8개가 적당하다. 매주 이정표면 이정표가 아니다.

## 8. 흔한 오류

- 막대 길이를 인원 수로 해석한다.
- 간트에 의존 관계 화살표를 손으로 그려 넣고 네트워크를 대신한다. 임계 경로는 계산으로 나온다.
- 이정표를 막대로 그린다.
- 계획 간트를 실행 중에 갱신하지 않는다. 실행 단계에서는 진척을 채우고 지연 구간을 표시한다 (`sw-sqa` 검토 시).
