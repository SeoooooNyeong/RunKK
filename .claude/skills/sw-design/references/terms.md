# 용어 대조표 (sw-design)

강의에서 쓰인 암기법·별칭과 이 스킬에서 쓰는 정식 용어의 대조표다. 본문에는 정식 용어만 쓴다.

| 강의 표현 | 정식 용어 | 뜻 |
|-----------|-----------|----|
| 대구인천 | 데이터 설계 → 구조(아키텍처) 설계 → 인터페이스 설계 → 절차 설계 | 설계 모델 4단계 |
| 응하이 결로 / 응 high 결 low | 응집도는 높게, 결합도는 낮게 | 좋은 설계의 기본 원칙 |
| 의논시절통순기 | 우연적 → 논리적 → 시간적 → 절차적 → 통신적 → 순차적 → 기능적 | 응집도 7등급, 약한 것부터 |
| 데스제외공내 | 데이터 → 스탬프 → 제어 → 외부 → 공통 → 내용 | 결합도 6등급, 낮은 것부터 |
| 입력선 / 출력선 | Fan-In / Fan-Out | 나를 부르는 수 / 내가 부르는 수 |
| 분할정복 | 단계적 분해(Stepwise Refinement) | 큰 문제를 작은 문제로 |
| 캡슐화 | 정보 은닉(Information Hiding) | 구조적 설계에서는 정보 은닉, 객체지향에서는 캡슐화. 같은 원리 |
| 블랙박스 모듈 | 정보 은닉이 적용된 모듈 | 안을 몰라도 쓸 수 있는 모듈 |
| 쓰레기통 패키지 | Fan-In 높음 + 논리적 이하 응집 | `common`, `util`의 전형 |
| 허브 | Fan-In·Fan-Out 모두 높은 패키지 | 모든 변경이 지나가는 곳 |
| DSM | 의존 행렬(Dependency Structure Matrix) | From × To 행렬 |
| I | 불안정도(Instability) = Fan-Out / (Fan-In + Fan-Out) | 0 안정, 1 불안정 |

## 결합도 등급 요약

| 등급 | 강도 | 핵심 |
|------|------|------|
| 데이터 | 1 | 단순 값만 |
| 스탬프 | 2 | 구조 전체 |
| 제어 | 3 | 플래그 |
| 외부 | 4 | 외부 자원 공유 |
| 공통 | 5 | 전역 변수 |
| 내용 | 6 | 내부 직접 접근 |

## 응집도 등급 요약

| 등급 | 강도 | 핵심 |
|------|------|------|
| 우연적 | 1 | 이유 없음 |
| 논리적 | 2 | 종류가 비슷 |
| 시간적 | 3 | 같은 시점 |
| 절차적 | 4 | 같은 순서 |
| 통신적 | 5 | 같은 데이터 |
| 순차적 | 6 | 출력 → 입력 |
| 기능적 | 7 | 한 기능 |

## 추상화 3종

| 종류 | 핵심 |
|------|------|
| 기능 추상화 | 입력 → 출력 과정을 이름 하나로 |
| 제어 추상화 | 제어 흐름 세부를 감춤 |
| 자료 추상화 | 데이터 + 연산을 묶음 |

정보 은닉은 추상화 3종에 들어가지 않는다.
