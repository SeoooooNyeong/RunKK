# 용어 대조표 (sw-test)

강의에서 쓰는 표현과 이 스킬의 용어를 대조한다. 본문에서는 왼쪽 표현을 쓰지 않는다.

## 테스트 일반

| 강의 표현 | 스킬 용어 |
|-----------|-----------|
| 검사, 시험 | 테스트 |
| 테스트 목적은 오류 존재를 보이는 것 | Myers 원칙 (`test-levels.md` 1절) |
| 검사 데이터의 집합 | 테스트 케이스 (입력·실행 조건·기대 결과) |
| 화이트박스 = 투명 박스, 내부 | 구조 기반 테스트 (`white-box.md`) |
| 블랙박스 = 검은 박스, 외부 | 명세 기반 테스트 (`black-box.md`) |

## 화이트박스

| 강의 표현 | 스킬 용어 |
|-----------|-----------|
| 기초 경로 검사, Basic Path Testing | 기초 경로 검사 |
| Tom McCabe, 순환 복잡도, Cyclomatic Complexity, CC | 순환 복잡도 V(G) |
| V(G) = E − N + 2 | 간선 − 노드 + 2 |
| 영역(region)의 수 | 영역 수 (바깥 포함) |
| 조건문·반복문 1개당 +1 | 단순 조건 수 + 1 |
| 제어 흐름도, Control Flow Graph | CFG |
| 노드 / 화살표(간선) / 영역 | 노드 / 간선 / 영역 |
| 독립 경로 | 새 간선을 하나 이상 포함하는 경로 |
| 조건 검사 / 루프 검사 / 데이터 흐름 검사 | 동일 |
| 단순·중첩·연결·비구조적 루프 | 동일 |
| CC 10 넘으면 리팩터링 권고 | 복잡도 10 초과 → `sw-code-review` 전달 |

## 블랙박스

| 강의 표현 | 스킬 용어 |
|-----------|-----------|
| 동치 분할 검사, Equivalence Partitioning | 동치 분할 |
| 타당한 값(Valid) / 타당하지 않은 값(Invalid) | 유효 클래스 / 무효 클래스 |
| 경곗값 분석, Boundary Value Analysis | 경곗값 분석 (min−1, min, min+1, max−1, max, max+1) |
| 원인-효과 그래프 검사, Cause-Effect Graphing | 원인-효과 그래프 → 결정표 |
| 오류 예측 검사, Fault-Based Testing, Mutation Testing | 오류 예측 체크리스트 |
| 비교 검사, Comparison Testing | 비교 검사 (회귀·이식·재구성에 사용) |

## 수준과 순서

| 강의 표현 | 스킬 용어 |
|-----------|-----------|
| 단위 테스트 = 클래스 테스트 | 단위 테스트 (단위 = 클래스) |
| 통합 테스트: Thread-based / Use-based | 스레드 기반 / 사용 기반 |
| 검증(Validation) | 검증 단계 = 요구사항 기반 테스트 |
| 시스템 테스트 | 시스템 테스트 (NFR, 운영 환경) |
| 단위 → 통합 → 검증 → 시스템 | 동일. 순서 고정 |
| V-모델: 요구분석↔시스템 테스트, 시스템 설계↔통합, 상세 설계↔단위 | V-모델 대응 |

## 요구사항 연결

| 강의 표현 | 스킬 용어 |
|-----------|-----------|
| 검증 가능성(Verifiability) | 모든 요구에 TC 1개 이상 |
| 추적 가능성(Traceability) | FR/NFR ↔ 설계 모듈 ↔ TC 추적표 |
| 기능 요구 / 비기능 요구 | FR-nnn / NFR-nnn |
