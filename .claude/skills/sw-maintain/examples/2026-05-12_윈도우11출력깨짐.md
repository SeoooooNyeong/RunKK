## 3. 기존 시스템 이해 (영향 범위)

| 항목 | 내용 | 출처 |
|------|------|------|
| 관련 요구 ID | FR-021 성적표 출력, NFR-008 이식성 (Windows 10 이상, Edge·Chrome·Safari) | srs.md 추적표 |
| 수정 대상 모듈 | grade.GradeReportPrinter | design-oo.md 5.6, 추적표 |

| 의존 모듈 (Fan-In) | GradeReportPrinter ← GradeController (1). FontConfig ← GradeReportPrinter, academic.CertificatePrinter (2) | design-review.md v1.2 의존 행렬 |
| 파생 데이터 | 없음 (PDF는 생성 후 저장하지 않음) | |

원인 가설: FontConfig가 `C:\Windows\Fonts\malgun.ttf`를 절대 경로로 읽는다. Windows 11 23H2 일부 이미지에서 맑은 고딕이 사용자 폰트 폴더(`%LOCALAPPDATA%\Microsoft\Windows\Fonts`)에 설치되어 시스템 폴더에 없다. 폰트 로드 실패 시 예외 없이 기본 폰트(한글 미지원)로 대체한다.

| 작성자 불명 또는 퇴사 | 아니오 |
