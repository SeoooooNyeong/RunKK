# 용어 대조표 (sw-estimate)

강의의 암기 표현·약어와 본문 용어를 대조한다. 본문에는 암기법을 쓰지 않는다.

| 강의 표현 | 본문 용어 | 의미 |
|-----------|-----------|------|
| "뭐니 뭐니 해도 머니" | 비용 산정의 중요성 | 비용이 가장 중요한 관리 대상 |
| PM | 인월(Person-Month) | 한 사람이 한 달 일하는 양. 기간 중심 |
| MM | 인월(Man-Month) | 한 달에 필요한 사람 수. 사람 중심 |
| LOC / KLOC | 코드 라인 수 / 1,000라인 | 규모 단위 |
| (a + 4m + b) / 6 | 3점 가중 평균 | 낙관·기대·비관치로 예측치 계산. PERT 공식과 같은 형태 |
| 하향식 (Top-down) | 전문가 감정, 델파이 | 전체 → 세부 |
| 상향식 (Bottom-up) | LOC, Effort per Task | 세부 → 합산 |
| COCOMO | Constructive Cost Model | Boehm, LOC 기반 회귀식 |
| Organic / Semi-detached / Embedded | 기관형(조직형) / 반분리형 / 내장형 | COCOMO 프로젝트 유형. 50K / 300K 경계 |
| Basic / Intermediate / Detailed | 기본형 / 중간형 / 발전형 | COCOMO 정확도 단계 |
| Cost driver | 비용 영향 요인 | Intermediate의 15개 보정 요인 (제품·컴퓨터·인력·프로젝트) |
| "Putnam은 SLIM하다" | Putnam 모형 → SLIM 도구 | Rayleigh-Norden 곡선 기반 생명주기 예측 모형과 그 자동화 도구 |
| "FP는 ESTIMACS다" | 기능 점수 → ESTIMACS 도구 | Albrecht의 기능 점수 모형과 그 자동화 도구 |
| Rayleigh-Norden 곡선 | 노력 분포 곡선 | 시간에 따른 인력 투입이 종 모양 |
| EI / EO / EQ / ILF / EIF | 외부 입력 / 외부 출력 / 외부 질의 / 내부 논리 파일 / 외부 인터페이스 파일 | 기능 점수 5요소 |
| UFP / VAF | 미조정 기능 점수 / 영향도 보정 계수 | FP = UFP × VAF |
| 40-20-40 | 노력 배분 기준 | 분석·설계 40, 코딩 20, 테스트 40 |
| "COCOMO는 코드, Putnam은 곡선, FP는 기능" | 세 모델의 기반 | LOC / Rayleigh-Norden / 기능 요소 |
