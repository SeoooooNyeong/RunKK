## 2. 범위와 용어

하는 일: 아바타 머리 전송·합성 시간, 홈 복귀 요청 수, 토큰 갱신, 업로드 압축, 일반 응답 디스크 캐시, 정적 파일 전송량, 크루런 결과 재조회 조건, 아바타 그을림 상한과 목·깃 맞춤, 시스템 막대(edge-to-edge), 크루런 카드 단추, 기록 상세 → 런바디 상세, 재평가 화면 구성, 배치 중 평가 화면 요구 삭제.

하지 않는 일: 머리 PNG 팔레트 압축, 통짜 머리 엔드포인트 삭제, 워치 화면, 옷 자산 재제작, 서버 nginx 핫픽스에 들어간 부분, 대결 결과 보류·친구 초대 취소(U-29 범위 밖 유지).

| 용어 | 뜻 |
|------|----|
| 머리 층 | 셀카 머리의 face·eyes·hair(정면)와 rightFace·rightEyes·rightHair(옆모습) PNG 한 장 |
| 머리 메타 | 머리 층을 합성하는 데 필요한 이미지 없는 값(정렬, 목 마스크, 피부색 등) |
| 첫 표시 시간 | 앱 프로세스 시작부터 홈 큰 아바타가 내 머리로 그려진 첫 프레임까지 |
| 다시 읽기 간격 | 홈이 같은 자료를 서버에서 다시 읽기 전에 지나야 하는 최소 시간 |
| 미리 갱신 | 접근 토큰이 만료되기 전에 새 토큰을 받는 것 |
