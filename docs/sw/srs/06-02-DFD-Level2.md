#### 6.1.4 Level 2

#### Level 2 — 프로세스 1 회원 관리

v0.10 변경 (CR-03, CR-09, CR-02, CR-07, CR-08):

- 1.1: 게스트의 소셜 계정 연동(FR-198)으로 계정연동요청(배경도 L0-32)과 계정연동결과(회원응답의 구성)를 더했다. 제공자 인증은 기존 인증요청·인증결과를 쓴다. 연동하면 회원레코드의 계정유형·제공자종류·제공자계정ID를 쓰고, 접속할 때 마지막접속일시를 쓰므로 1.1 → ║D1║ 회원레코드를 더했다. 연동하지 않은 게스트가 로그아웃하면(FR-002) 확인 뒤 기기의 미전송 기록을 지우므로 1.1 → ║D15║ 회원삭제지시를 더했다. 자료 유실 고지(FR-199)는 로그인결과(로그아웃 확인)와 회원가입결과(게스트 시작 직후)·프로필(설정 화면)에 담는다.
- 1.2: 게스트로 시작(FR-197)으로 게스트시작요청(배경도 L0-31)을 더했다. 결과는 회원가입결과, 기록은 회원레코드(계정유형 = 게스트)다. 회원가입요청은 동의 단계 하나로 줄었다(FR-003, 구성은 6.2).
- 1.4: 화면 테마(FR-203)와 대결설정의 근접알림여부(FR-109)는 기존 설정변경요청·설정결과의 설정항목으로 받는다. 새 흐름은 없다.
- v0.13 변경 (CR-51): 1.4가 첫 사용 가이드(FR-231)의 가이드조작(건너뛰기·다음·시작하기)을 받아 회원레코드의 가이드확인여부를 켜고, 가이드 화면(가이드화면)을 러너에게 낸다. 가이드조작은 회원요청의, 가이드화면은 회원응답의 구성이다. 저장소 흐름은 기존 회원레코드 읽기·쓰기를 쓴다 (v0.13 신규, CR-51).
- 1.5: 미이용 게스트 자료 파기(FR-200)는 러너의 요청 없이 ║D1║의 계정유형·마지막접속일시로 대상을 골라 탈퇴와 같은 회원삭제지시를 낸다. 크루 채팅 메시지(FR-021)를 위해 1.5 → ║D18║ 회원삭제지시를 더했다.
