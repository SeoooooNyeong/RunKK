시나리오 S-EV-1 코치님 이벤트(정상): 러너가 알림함을 연다 → 맨 위 「이벤트」 항목에 점이 있다 → 누르면 이벤트 목록 → 「코치님을 이겨라」 카드(새 이벤트, D-8, 0 / 2)를 누른다 → 상세 페이지가 열리고 내 응모 0 / 2가 보인다 → 「셀럽런 도전하기」를 누르면 기록런 탭 셀럽런 목록이 열린다 → 주세빈 코치님 기록과 5km 셀럽런을 해 이긴다 → 이벤트 포인트 500P가 적립된다 → 상세를 다시 열면 내 응모 1 / 2.

- 예외 S-EV-1a: 진다, 포기한다, 판정이 보류된다 → 응모와 포인트가 없다([임시:FR-성-6], [임시:FR-성-8]).
- 예외 S-EV-1b: 같은 코치님을 또 이긴다 → 응모는 그대로 1, 포인트도 더 없다.
- 예외 S-EV-1c: 포인트 적립이 실패한다(일시 장애) → 대결 결과는 확정되고, 다음 셀럽런 승리 때 놓친 포인트를 채운다.
- 예외 S-EV-1d: 기간이 끝난 뒤(11-17 00:00 이후) 이긴다 → 응모와 포인트가 없고 카드는 「지난 이벤트」 탭으로 간다.
- 예외 S-EV-1e: 상세 페이지를 받지 못한다 → 오류 안내와 다시 시도. 내 참여만 못 읽으면 내 응모 영역만 숨긴다.

시나리오 S-EV-2 베타 이벤트(정상): 러너가 이벤트 목록에서 「1km 걷거나 달리기」를 연다 → 산책 코스 C, D, E 가운데 하나를 고른다 → 「달리러 가기」를 누르면 위치 권한을 확인하고 자유런 화면이 열린다 → 1.1km를 걷고 저장한다 → 상세의 내 응모가 1 / 1, 「참여 중」이 된다.

- 예외 S-EV-2a: 0.9km에서 끝낸다, 너무 느려 무효 기록이 된다 → 응모가 없다.
- 예외 S-EV-2b: 위치 권한을 거절한다 → 자유런 화면으로 가고 그 화면의 권한 안내를 따른다(FR-030).

시나리오 S-EV-3 운영자 수정(정상): 운영자가 관리 기능으로 beta-1km의 종료일시를 하루 늘린다 → 감사기록(기준값변경, EVENT:beta-1km, 전후 값)이 남는다 → 앱 목록의 기간 줄과 D-day가 다음 조회부터 바뀐다. 상세 페이지의 날짜 글자는 페이지를 다시 배포해야 바뀐다.

- 예외 S-EV-3a: 종료일시를 시작일시보다 앞에 둔다, 주소이름이 겹친다, 설정이 종류와 안 맞는다 → 「값이 올바르지 않음」으로 거부.
- 예외 S-EV-3b: 화이트리스트에 없는 계정 → 거부(FR-173).
