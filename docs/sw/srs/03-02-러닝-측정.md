| 명칭 | 러닝 진행 지표 표시 |
| 설명 | 시스템은 러닝 중 누적 거리, 경과 시간, 현재 페이스, 평균 페이스를 러너에게 1초 간격으로 갱신해 보여 주어야 한다 |
| 입력 | 유효위치포인트, 일시정지요청 |
| 처리 | 누적 거리 = 유효 위치 포인트 사이 거리의 합. 표시 단위는 FR-009를 따른다 누적 거리가 0이면 페이스는 값 없음(빈 값)으로 두고 측정은 계속한다 (v0.9 추가, test.md TC-3170). 일시정지 중(FR-194)에는 누적 거리와 경과 시간을 늘리지 않고 "일시정지" 상태를 보인다. 평균 페이스는 정지 시간을 뺀 운동 시간으로 계산한다 (v0.10 추가, CR-01). 일시정지 중에도 심박은 계속 표시하고, 현재 페이스는 빈 값으로 둔다 (v0.10 보완, test.md v0.6 TF-VA-36). 폰 측정 화면의 항목은 자유런이 거리, 시간, 평균 페이스, 심박이고 현재 페이스는 보이지 않는다(워치는 현재 페이스를 보인다, FR-042). 대결은 경과 시간, 현재 페이스, 평균 페이스를 보인다(FR-088). 외부 지도 서비스(C-005)의 지도 위에 경로선과 아바타를 보인다. 지도는 러너의 현재 위치를 따라 움직이고, 러너는 지도를 확대·축소만 할 수 있다(옮기기·돌리기·기울이기 없음). 지도를 띄울 수 없으면 경계선과 격자를 그린 바탕 위에 경로선과 아바타를 보이고 측정은 그대로 이어 간다. 지도 서비스로 보내는 자료는 NFR-043을 따른다 (v0.15 변경, CR-60: v0.13 CR-37의 "지도 타일 없이"를 바꾼다). 이웃한 두 유효 위치 포인트 사이 속도가 시속 25km를 넘으면 그 사이 거리를 누적 거리에 더하지 않는다. 과속 구간의 기준은 FR-047과 같다 (v0.11 추가, CR-11). 과속 구간의 시간은 측정 중 운동 시간에서 빼지 않고 그대로 보내며, 서버가 저장할 때 한 번만 뺀다(FR-047) (v0.11 보완, test.md v0.7 TF-V7-01). |
