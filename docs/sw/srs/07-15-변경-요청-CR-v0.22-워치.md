##### 7.13.18.2 모델 반영

- DFD Level 2(프로세스 2): L2-2-44 러너 → 다시보내기요청 → 2.7 러닝 기록 전송. Level 1에서는 복합 흐름 러닝조작의 구성으로 들어가므로 균형이 유지된다(06-02 균형 점검 "러닝조작" 행의 하위 프로세스에 2.7을 더함). 워치 거부 건수는 D15 미전송 기록 보관함(워치 쪽)에서 2.7로 가는 완료러닝기록(L2-2-30)에서 세므로 새 흐름이 아니다.
- 소단위 명세 2.7: "IF 서버가 기록을 받지 않음(4xx) THEN 거부사유와 함께 D15에 남기고 자동 재전송에서 뺀다. IF 다시보내기요청 THEN 거부 기록을 미전송으로 되돌려 보낸다"를 FR-273·FR-040 처리 문장으로 대신한다.
- 상태: 완료러닝기록의 전송상태는 미전송 → (거부) → 거부 → (다시 보내기) → 미전송이고, 저장에 성공하면 보관함에서 지운다(design-oo 05-20 3.3).
