## 입력·예외

- 셀카는 JPEG·PNG, 최대 1MiB다. 이미지 크기는 AI의 4096×4096 제한으로 검증한다.
- 앱의 userId는 받지 않는다. 회원 ID는 인증 속성에서 읽는다.
- 기존 FACE_TRANSFER 동의·SELFIE_ENABLED·성공 일일 한도·실패 상한을 지킨다.
- 작업 미완료는 변환 실패로 안내하지 않는다. 실패는 error.code로 전달한다.
- 회원 식별자 외에 이름·연락처·프로필은 AI에 보내지 않는다. 기존 NFR-024의 식별자 미전송 문장은 이 경계 계약과 충돌하므로 공용 담당에게 변경을 요청한다.
- 얼굴 원본·결과를 로그에 넣지 않는다. Node가 결과를 보관하며 얼굴 파기 미지원은 #257의 배포 확인 항목이다.
