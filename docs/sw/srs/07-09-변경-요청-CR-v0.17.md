#### 7.13.13 소리·첫 화면·오늘 계획 페이스 반영 변경 요청 (2026-10-31, v0.17)

출처: 사용자 결정 D139~D148(`runkk-work/figma-1029/decisions-1029.md` 표의 끝 열 줄). 2026-10-31 오후 앱에 들어간 변경이다. 승인자: 사용자(대화 결정, 2026-10-31. 문서 반영을 스킬 순서대로 끝까지 진행하도록 위임). 구현 사실은 코드 저장소 S15P31A207-fig의 브랜치 feature/runkk-figma-v1 커밋 242612e9(MR !53)를 읽어서만 확인했다. 코드는 고치지 않았다.

처리 원칙:

- 요구가 바뀐 결정은 CR로 FR·NFR을 고치거나 새로 만든다. 번호는 다시 매기지 않는다. 새 FR은 마지막 번호 FR-233 다음인 FR-234부터, 새 NFR은 NFR-044 다음인 NFR-045부터 붙인다. 삭제한 요구는 없다.
- 결함 수정(D147)은 문서에 없던 동작 규칙을 해당 FR의 처리에 보강한다(요구 보강). 기능 범위는 바뀌지 않는다.
- 그림 자산 정정(D143)은 요구 변경이 없다. 그림 크기 조정(D145)은 표시 변경이며 FR-162 처리에 한 문장으로만 남긴다.
- 재생 라이브러리 이름은 2.4 제약 조건(C-021)과 이 절의 구현 대조·비고에만 쓴다. 3~5장은 기술 중립 표현을 쓴다.
- 질문 없이 기본값으로 정한 것은 아래 "분석 담당 판단"(J-1~J-8)에 적었다. 값을 정하지 않고 분석 담당이 낸 값은 본문에 **(제안)** 으로 표시했다.
