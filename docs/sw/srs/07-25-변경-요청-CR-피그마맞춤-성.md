##### 7.13.28.3 시나리오

- S-FG-1 크루 찾기(정상): 러너가 크루 탭에서 검색 칸을 누른다 → 크루 검색 화면에서 「한강」을 찾는다 → 「검색 결과 2개」와 카드 두 장 → 카드를 눌러 크루 상세(만든 날, 「지난 주 달린 거리」, 「누적 크루런 횟수」, 최근 크루런 3건) → 「가입하기」.
- S-FG-1a 쿨타임: 어제 저녁 크루를 탈퇴한 러너가 상세를 연다 → 단추가 회색 「05:12:09 후에 가입할 수 있어요」로 1초마다 줄어든다.
- S-FG-2 초대 코드(정상): 「초대 코드」 → 시트에 6자 → 「확인」 → 크루 카드와 「가입하기」 → 가입. 예외 S-FG-2a: 틀린 코드 → 칸이 오류 모양, 「일치하는 크루가 없어요. …」.
- S-FG-3 반복 일정(정상): 크루원이 토요일 07:00 5km 「매주 토요일」로 올린다 → 일요일 0시 지나 시스템이 다음 주 토요일 07:00 회차를 올리고 모집 알림을 보낸다 → 작성자가 상세 ⋯ 「수정하기」에서 「반복 안 함」으로 바꾼다 → 그다음 일요일에는 올리지 않는다.
- S-FG-4 채팅 시스템 메시지(정상): 크루원 A가 5.20km 러닝을 저장한다 → 채팅 탭을 보고 있던 B에게 「A님이 러닝을 마쳤어요」와 5.20km가 바로 뜬다(경과 시간은 싣지 않는다, 7.13.28.5).
- S-FG-5 목표 초과(정상): 목표 80km에 84.23km → 레이스 탭 「105%」, 막대 꽉 참, 위에 「10월 4주 목표 달성」 띠. 그 주 처음 들어오면 축하 팝업이 한 번 뜬다.
- S-FG-6 크루장 넘기기(정상): 크루장이 크루원 목록에서 B를 누른다 → 팝업(티어, 레벨, 나이, 성별, 가입일) → 「크루장 넘기기」 → 확인 → 넘김.
- S-FG-7 배경 해금(정상): 러너가 러닝으로 대전과 세종 랜드마크를 넘는다 → 내 러너 화면을 열면 「세종 배경을 열었어요」(더 먼 곳), 「이번 러닝으로 함께 연 배경」에 대전 → 「배경 바꾸기」(홈이 아니라 내 러너 화면에 뜬다, 7.13.28.5).
