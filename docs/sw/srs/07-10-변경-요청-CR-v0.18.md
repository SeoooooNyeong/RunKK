#### 7.13.14 워치 v2(워치 단독 러닝, 메인 4안) 반영 변경 요청 (2026-10-31, v0.18)

출처: 2026-10-31 사용자 결정 W01~W12와 분석 담당 기본값(`runkk-work/watch-v2/decisions.md`), 사용자 지시 "watch 작업해야돼 메인화면은 4안으로 진행하고 기능은 크루런만 빼고 작업해줘", 피그마 "Runkk · Galaxy Watch (화면별 + 모션)"(파일 6iPzSQqOUFG8twJUYKLJmU, 페이지 144968:2). 승인자: 사용자(대화 결정, 2026-10-31. W08로 srs → design-oo → 설계 검증 → 구현 → 코드 리뷰 → 시험 순서의 문서 반영을 위임). 아직 구현되지 않은 변경이다. 현재 코드는 S15P31A207-fig develop 계열(0d1b6644)의 wear·wear-contract 모듈을 읽어서만 확인했다(아래 구현 대조).

처리 원칙:

- 와이어프레임 결정 W-06(워치 표시 전용, v0.8)과 그에 따른 C-002, A-009, FR-046 삭제를 W01로 다시 바꾼다. 삭제된 FR-046과 A-009 번호는 되살리지 않고, 워치 단독 러닝 요구는 새 번호 FR-240~FR-260, 가정 A-013·A-014로 만든다. 번호는 다시 매기지 않는다.
- 새 FR은 FR-239 다음인 FR-240부터, 새 NFR은 NFR-047 다음인 NFR-048부터, 새 제약은 C-022, 새 시나리오는 S-27부터 붙인다.
- 2026-10-31 워치 v2 결정 W01~W12(하이픈 없음)는 와이어프레임 결정 W-01~W-xx(7.10.3, 하이픈 있음)와 다른 목록이다. 본문 출처에는 "2026-10-31 사용자 결정 W01"처럼 날짜를 붙여 구분한다(J-3).
- 폰 기능은 바꾸지 않는다. 기존 동행 표시(폰 측정, 워치 표시·심박 전송)는 W07로 유지하고, 워치에서 시작한 러닝만 워치가 측정한다.
- 기술·제품 이름(Wear OS, API 수준)은 2.4 제약 C-022와 이 절의 구현 대조에만 쓴다. 3~5장은 기술 중립 표현을 쓴다.
- 질문 없이 정한 것은 아래 "분석 담당 판단"(J-1~J-16)에 적었다. 값을 정하지 않고 분석 담당이 낸 값은 본문에 **(제안)** 으로 표시했다.
