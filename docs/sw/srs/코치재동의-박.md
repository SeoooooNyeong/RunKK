# AI 코치 진입과 최신 동의

> 작성: 2026-11-09 | 버전: v0.31(같은 판 보완, sw-sdlc merge) | S15P31A207-273, FR-015, CR-133, Figma G-24·G-34·G-35

- 런바디에서 AI 코치를 열면 대화 목록 요청으로 서버의 기능 공개와 최신 동의를 확인한다. 확인 전 또는 확인 실패 시 질문을 전송하지 않는다.
- 서버가 CONSENT_REQUIRED를 반환하면 같은 코치 경로에서 안내를 표시한다. 동의 설정으로 이동하면 기존 동의 관리에서 최신 안내를 확인할 수 있다.
- 최신 고지는 러닝 집계값·질문 원문 전송, 처리위탁·국외 이전, 마지막 질문 뒤 90일 대화 보관, 미동의 시 제한과 철회를 알린다.
- 운영자가 제공한 고지에 러너가 동의하면 기존 LLM_TRANSFER 항목에 2판을 저장한다. 코치에서 왔다면 저장 성공 뒤 코치로 돌아와 서버 상태를 다시 확인한다. 질문을 자동 전송하지 않는다.
- 일반 설정에서 AI 전송 동의를 켤 때도 같은 고지와 2판을 쓴다. 가입의 기존 동의 요청은 1판으로 유지한다. 동의 철회는 기존 API를 사용한다.
- 대화 목록의 항목은 같은 대화 ID로 질문을 이어 간다. 질문 본문의 과거 문답 복원은 기존 계약 범위 밖이다.
