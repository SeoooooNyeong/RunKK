### 3.1 회원 관리 (DFD 프로세스 1)

| 항목 | 내용 |
|------|------|
| ID | FR-001 |
| 명칭 | 소셜 계정 로그인 |
| 설명 | 러너는 C-007에 정한 두 소셜 로그인 제공자 중 하나의 계정으로 로그인할 수 있어야 한다 |
| 입력 | 로그인요청(제공자종류), 인증결과 |
| 처리 | 소셜 로그인은 기존 회원의 로그인과 게스트 회원의 소셜 계정 연동(FR-198)에 쓴다 (v0.10 변경, CR-09). 제공자에 인증요청을 보낸다. 인증에 성공하고 회원 파일에 같은 제공자계정ID가 있으면 로그인을 완료한다. 회원이 아니면 "가입필요"를 돌려주고, 동의(FR-003)를 거쳐 소셜 계정이 연동된 회원을 바로 만들거나 게스트로 시작(FR-197)할 수 있게 안내한다 (v0.10 변경, CR-09). 인증에 실패하면 실패 사유를 보여 주고 재시도를 안내한다. 제공자가 응답하지 않으면 "로그인 제공자 연결 실패"를 보여 준다. 두 제공자를 모두 지원한다(C-007) 접근 토큰은 발급 1시간 뒤(정각)에 만료되고, 만료된 토큰은 거부한다. 접근 토큰 갱신 서버의 일시 오류(5xx·429·연결 실패)는 로그아웃으로 보지 않아 로그인 상태와 기기의 미전송 기록을 그대로 두고 원래 요청만 일시 오류로 실패시켜 다시 시도할 수 있게 하며, 갱신이 거부(400·401·403)될 때만 로그인 상태를 해제한다 (v0.9 추가, test.md TC-2031, TC-1450). |
| 출력 | 인증요청, 로그인결과(로그인완료 / 가입필요 / 로그인실패 + 실패사유) |

| ID | FR-003 |
| 명칭 | 회원 가입 |
| 설명 | 러너는 인증된 소셜 계정으로 회원 가입을 할 수 있어야 한다 |
| 입력 | 신규계정정보, 회원가입요청(동의항목별 동의여부), 가상기록(가상닉네임) |
| 처리 | 가입은 동의 한 단계로 받는다. 동의 화면에서 필수 동의 3종, 만 14세 이상 확인, 선택 동의 2종을 받고, 프로필·기록 공개 범위·성향 태그·아바타 단계는 두지 않는다 (v0.10 변경, CR-03, CR-04). 동의 화면에 "전체 동의"를 두어 필수 동의와 선택 동의를 한꺼번에 켜게 하고, 선택 동의는 따로 끌 수 있다. 기록 공개 범위 고지 문구는 두지 않는다(FR-028 삭제됨) (v0.13 변경, CR-39). 프로필은 프로필 편집(FR-007)에서, 아바타는 아바타 화면(FR-155, FR-158)에서 나중에 정한다 (v0.10 변경, CR-03). 필수 동의 3종(이용약관, 개인정보수집, 위치수집)이나 만 14세 이상 확인(FR-004) 중 하나라도 빠지면 가입을 거부하고 빠진 항목을 표시한다. 가입 때 받는 선택 동의는 2종(마케팅수신, LLM전송)이다. 얼굴변환전송 동의는 아바타 만들기 단계에서(FR-016), 심박수집 동의는 워치 연동을 켤 때(FR-014) 받는다(N-23). 닉네임은 제공자제공이름으로 정하고, 제공자제공이름이 없으면 FR-197 규칙("러너" + 숫자 4자리)으로 붙인다 (v0.10 변경, CR-03). 가입에는 닉네임 입력 단계가 없으므로 제공자제공이름이 2자 미만이면 없을 때와 같이 FR-197 규칙("러너" + 숫자 4자리)으로 붙이고, 20자를 넘으면 앞 20자만 쓴다. 이 경우에도 가입을 거부하지 않는다 (v0.10 보완, test.md v0.6 TF-VA-32). 닉네임은 2~20자이고 다른 회원 닉네임이나 가상닉네임(FR-104)과 겹치면 뒤에 숫자 4자리를 붙인다. 가입이 끝나면 계정유형이 연동회원인 회원레코드를 만들고 동의 내역을 동의이력과 감사기록에 남긴다 (v0.10 변경, CR-09). 닉네임에 숫자 4자리를 붙여 20자를 넘게 되면 닉네임 앞 16자만 남기고 숫자 4자리를 붙여 20자로 맞춘다 (v0.9 정정, test.md TC-3018). 닉네임의 글자 수는 사용자에게 보이는 글자(코드 포인트) 단위로 세고 입력 그대로 저장한다 (v0.9 추가, test.md TC-3025). 가입 화면에는 기록 공개 고지 문구를 두지 않는다(FR-028 삭제). 대신 필수 동의 "개인정보 수집·이용"이 여는 개인정보 처리방침 본문에 "러닝 기록은 기본으로 전체 공개이며 설정에서 바꿀 수 있다"를 적는다 (v0.14 추가, CR-56). |
