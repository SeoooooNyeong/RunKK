#### 7.13.12 확인 필요 3건의 사용자 결정 반영 변경 요청 (2026-10-31, v0.16)

출처: 사용자 결정 D128~D130(`runkk-work/figma-1029/decisions-1029.md` "2026-10-30~31 후속 결정" 표의 끝 세 줄). v0.15가 "확인 필요"로 남긴 세 건(런바디 진입점과 공개 시기 FR-067, 다른 러너에게 보이는 내 아바타 성별 FR-162, 개인 기록의 동의 규칙 FR-170)에 대한 결정이다. 승인자: 사용자(대화 결정, 2026-10-31). 구현 사실은 코드 저장소 S15P31A207-fig의 작업 트리(커밋하지 않은 변경 포함)를 2026-10-31에 다시 읽어서만 확인했다.

처리 원칙: 7.13.11과 같다. 요구가 바뀐 결정은 CR로 FR을 고치고, 번호는 다시 매기지 않으며 삭제한 요구는 없다. 문서의 사실 오류를 바로잡은 것은 CR-81로 따로 적었고 요구는 바뀌지 않는다.

설계 영향(`/sw-design-oo`): 다른 러너에게 보이는 표시 성별(랭킹·프로필 응답 항목, 회원별 무작위 값 고정 방법), 코치 실명 등록(실명등록동의와 이름 형식), 런바디 잠금(UnreleasedFeature.RUNBODY, BetaLock 리포트 경로). 시험 영향(`/sw-test`): FR-067 케이스를 2차 배포로 옮기고 1차 배포 앱에서 리포트 경로 잠금 케이스(FR-223), FR-064·FR-065의 화면 없는 시험, FR-162·FR-006·FR-070 표시 성별 케이스(구현 뒤), FR-170 코치 실명 등록과 동의 값 일부 누락 거부 케이스.
