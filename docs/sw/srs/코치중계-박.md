# AI 코치 중계와 재동의 서버 계약

> 작성: 2026-11-09 | 버전: v0.31(2026-11-09 병합, 7.13.26) | 입력: S15P31A207-241·273, FR-015·FR-261~264, 11/06 사용자 결정, develop 04bedc08

- 회원이 코치 질문을 보낼 때 서버는 인증에서 회원 ID를 얻어야 한다.
- 서버는 기존 LLM_TRANSFER 항목의 최근 동의가 현재 판인지 확인해야 한다.
- 기존 동의 기록과 판 번호 없는 동의 요청은 1판이다. 기존 PUT /api/v1/me/consents/LLM_TRANSFER?version=2로 2판을 명시한다.
- 동의를 철회한 회원은 코치 접근을 다시 차단해야 한다. 일반 LLM 코멘트의 동의 판정은 기존 동의 여부를 따른다.
- 코치 기능은 운영 기준값 COACH_ENABLED가 켜졌을 때 공개한다.
- 질문은 앞뒤 공백을 뺀 1~500 코드 포인트이고 요청 본문은 최대 8 KiB다. 다른 회원의 대화와 90일이 지난 대화는 이어갈 수 없다.
- 코치 한도는 한국 시간 하루 기준이고, AI의 정상 done을 확인한 요청만 차감한다.
- 과거 대화 목록은 제목과 마지막 질문 시각을 보낸다. 과거 문답 본문 조회는 현재 계약에 없다.

| 앱 요청 | 성공 응답 |
|---|---|
| POST /api/v1/coach/questions, conversationId·text | 200 SSE started → delta → done 또는 failed |
| GET /api/v1/coach/conversations | 200 JSON 배열 conversationId·firstQuestion·lastAskedAt |
| PUT /api/v1/me/consents/LLM_TRANSFER?version=2 | 기존 ConsentResult, 동의 이력에 2판 기록 |

- 요청 전 거부는 code·message다. 기능 닫힘·미동의 403, 대화 만료 410, 질문 길이 400, 한도 429다.
- AI 오류·연결 실패·중간 종료는 failed RETRY로 안내한다. AI 404·429는 대화 만료·한도 응답에 대응한다.
- AI 서버는 접수를 기준으로 별도 안전 한도를 적용한다. AI가 429를 반환해도 백엔드의 완료 건수는 늘지 않는다.
- AI의 meta가 시작된 대화의 색인을 등록한다. 답변 전 실패해도 이미 수락된 대화는 다시 사용할 수 있다.
- 기존 질문·목록 경로를 사용한다. 앱 어댑터·화면과 최신 고지의 사용자 확인은 후속 통합 범위다.
