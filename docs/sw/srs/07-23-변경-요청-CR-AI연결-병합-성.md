##### 7.13.26.1 변경 요청

| CR | 요청 | 결정 | 반영 위치 |
|----|------|------|-----------|
| CR-179 | writer 모델 관리 범위와 등록 동작(#243 사용자 확인) | 승인. 모델 관리(FR-268~FR-271)의 대상은 런바디 분석 문구를 쓰는 writer다. writer 변경은 코치 답변 모델에 적용되지 않는다. 등록된 모델이 없을 때의 첫 등록은 바로 활성 모델이 된다. 같은 모델ID를 다시 등록하면 거부하지 않고 주소와 메모를 갱신하며 활성 여부는 그대로 둔다. 다른 새 모델 등록은 활성 모델을 바꾸지 않는다. 등록 주소는 배포 설정 writer 주소 목록(`RUNKK_WRITER_MODEL_URLS`, 기본 `http://writer:8080`)에 있는 것만 받는다. 감사는 호출 전 REQUESTED, 정상 응답 뒤 SUCCEEDED로 두 번 남긴다(V47 행위 WRITER_MODEL_REGISTER, WRITER_MODEL_ACTIVATE, WRITER_MODEL_ROLLBACK) | 03-07 FR-268~FR-271, 06-04b 행위종류, 05 5.3 보충, 07-11 추적, design-oo 05-19 D-446 |
