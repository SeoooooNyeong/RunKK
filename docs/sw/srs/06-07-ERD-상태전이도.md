### 6.4 ERD / 상태전이도

#### 6.4.1 개체 관계도(ERD)

저장소가 19개이고 저장소 사이에 회원ID·크루ID·기록ID·대결ID로 이어지는 관계가 있어 ERD를 붙인다. 개체는 6.2 자료사전의 레코드와 같은 이름이다. 테이블·키 설계는 설계 단계의 일이다. v0.10에서 크루채팅메시지·리액션·신고·공동목표·랜드마크배경과 투표응답·게시사진·정지구간을 더했다(7.13, CR-01·CR-06·CR-08).

자유런(러닝모드 일반)의 측정 상태다. 6.4.4 러닝 기록 전송의 앞 단계이며, 여기의 (종료)가 6.4.4의 미전송으로 이어진다. 대결·크루런은 일시정지가 없어(W-21) 측정 중에서 바로 종료로 간다. 일시정지 구간은 러닝기록의 정지구간으로 남고 거리·경과시간·평균페이스에서 뺀다(FR-034, FR-036).

 [시작] ──러닝시작요청 (FR-030)──▶ (측정 중)
 (측정 중) ──일시정지요청: 일시정지, 자유런, 폰 화면·진행 알림·워치 요청 (FR-194)──▶ (일시정지)   (v0.13 변경, CR-26)
 (일시정지) ──일시정지요청: 재개, 폰 화면·진행 알림·워치 요청 (FR-194)──▶ (측정 중)   (v0.13 변경, CR-26)

#### 6.4.9 상태전이도 — 배치고사 (v0.24 신규, CR-139)

대상은 회원레코드의 티어와 배치진행이다. 임시 티어는 본인에게만 보이고(FR-282), 확정 전까지 회원 티어는 언랭이다.

```
 [가입] ──▶ (배치 중 0/3) ──1판 셈(유효, 포기 아님) (FR-275, FR-277)──▶ (배치 중 1/3, 임시 티어 = 1판 점수 단계)
 (배치 중 1/3) ──2판 셈 (FR-275, FR-277)──▶ (배치 중 2/3, 임시 티어 = 1·2판 평균 단계)
 (배치 중 2/3) ──3판 셈 (FR-278)──▶ (확정 티어 = 3판 평균 단계, 임시 티어 비움) ──▶ 재평가는 FR-027
 (배치 중 n/3) ──포기·무효·출발 전 취소·기록 미도착──▶ (배치 중 n/3) 그대로
 (배치 중 n/3) ──일반 러닝·친구 대결·셀프런·셀럽런──▶ (배치 중 n/3) 그대로
 (배치 중 n/3) ──탈퇴──▶ [끝] (배치진행 삭제, 재가입은 0/3)
 (확정 티어) ──유효 러닝 순번 10의 배수──▶ (확정 티어, 최근 10회 평균으로 갱신) (FR-027)
```

| 현재 상태 | 사건 | 조건 | 다음 상태 | 관련 FR |
|-----------|------|------|-----------|---------|
| 배치 중 0/3 | 배치판결과 | 본인 기록 유효, 포기 아님 | 배치 중 1/3 (임시 티어 = 1판 러닝점수의 단계) | FR-275, FR-277 |
| 배치 중 1/3 | 배치판결과 | 같음 | 배치 중 2/3 (임시 티어 = 1·2판 평균의 단계) | FR-275, FR-277 |
| 배치 중 2/3 | 배치판결과 | 같음 | 확정 티어 (3판 평균의 단계, 임시 티어 비움, 배치고사 완료 화면) | FR-278, FR-281 |
| 배치 중 n/3 | 배치판결과 | 포기·무효·출발 전 취소·기록 미도착 | 그대로 (같은 판 번호로 다시) | FR-275 |
| 배치 중 n/3 | 유효 러닝 저장 | 배치고사가 아닌 러닝, 순번 10의 배수 포함 | 그대로 (재평가 없음, 최근 10회 점수만 쌓음) | FR-022, FR-027 |
| 배치 중 n/3 | 탈퇴 | 없음 | 끝 (배치진행 삭제) | FR-021 |
| 확정 티어 | 유효 러닝 저장 | 순번 10의 배수, 3판째와 같은 순번 아님 | 확정 티어 (재평가) | FR-027 |

상태: 배치 중 0/3, 배치 중 1/3, 배치 중 2/3, 확정 티어. 배포 때 이미 티어가 있는 회원은 확정 티어에서 시작하고, 언랭 회원은 유효 러닝 수와 관계없이 배치 중 0/3에서 시작한다(J24-10).

#### 6.4.10 상태전이도 — 이벤트 진행상태 (다음 판 신규, [임시:CR-성-1])

대상은 이벤트 하나다. 진행상태는 저장하지 않고 지금 시각과 시작일시, 종료일시로 센다. 이벤트공개여부는 진행상태와 따로 바뀐다. 시각은 한국 시간이고 기간은 양 끝을 포함한다.

```
 [등록] ──▶ (예정) ──지금 시각 ≥ 시작일시──▶ (진행중) ──지금 시각 > 종료일시──▶ (종료) ──▶ [끝]
 (예정 | 진행중 | 종료) ──이벤트 수정(기간 바뀜)──▶ 새 기간으로 다시 센 상태 ([임시:FR-성-11])
 공개여부: (공개) ⇄ (비공개)  공개 전환 ([임시:FR-성-12])
```

| 현재 상태 | 사건 | 조건 | 다음 상태 | 관련 FR |
|-----------|------|------|-----------|---------|
| 시작 | 이벤트 등록 | 형식, 규칙 검사 통과 | 예정, 진행중, 종료 가운데 지금 시각에 맞는 것 | [임시:FR-성-10] |
| 예정 | 시각 흐름 | 지금 시각 ≥ 시작일시 | 진행중 (본이벤트목록에 없으면 새 이벤트 점) | [임시:FR-성-1], [임시:FR-성-3] |
| 진행중 | 시각 흐름 | 지금 시각 > 종료일시 | 종료 (응모와 포인트 판정 대상에서 빠짐) | [임시:FR-성-1], [임시:FR-성-6]~[임시:FR-성-8] |
| 어느 상태든 | 이벤트 수정 | 기간을 바꿈 | 새 기간으로 다시 센 상태. 응모 수도 새 기간으로 다시 센다 | [임시:FR-성-11] |
| 공개 | 공개 전환 | 끔 | 비공개 (앱 목록, 내 참여, 포인트에서 빠짐) | [임시:FR-성-12] |
| 비공개 | 공개 전환 | 켬 | 공개 | [임시:FR-성-12] |

상태: 예정, 진행중, 종료(진행상태)와 공개, 비공개(이벤트공개여부). 이벤트를 지우는 기능은 없다(비공개로 둔다).
