#### 3.3.1 누적 거리 랜드마크 목록 (운영 기준값, 결정 Q-65·Q-77)

이 목록은 운영 기준값(자료사전 "랜드마크목록")이라 FR을 바꾸지 않고 값을 고칠 수 있다. 표시 거리는 서울 기준 직선(대권) 거리로 통일하고, 아래 근사값을 채택했다(결정 Q-77). 값은 구현 전에 다시 확인해 운영 기준값으로 고칠 수 있다. 순서는 이 거리 기준이다(런던·파리가 LA 앞). 개인 단계(1~3단계) 랜드마크는 러너가 누적 거리로 넘을 때마다 아바타 배경으로 해금되고(FR-201), 러너는 해금한 배경 중 하나를 고를 수 있다(FR-202) (v0.10 추가, CR-06).

| 단계 | 랜드마크 | 거리(km) | 기준 | 이 랜드마크를 가장 최근에 넘었을 때 표기 |
|------|----------|----------|------|------|
| 1 국내 | 서울–인천 / 서울–개성 / 서울–대전 / 서울–전주 | 약 60 / 120 / 280 / 400 | 왕복 | "서울에서 ○○까지 달렸어요! (왕복 n회)" |
| 1 국내 | 서울–여수 / 서울–부산 / 서울–제주도 | 약 650 / 800 / 900 | 왕복 | 같은 표기 |
| 2 동아시아 | 베이징 / 도쿄 / 타이베이 | 약 950 / 1,150 / 1,480 | 편도 | "서울에서 ○○까지 달렸어요!" |
| 2 동아시아 | 홍콩 / 하노이 / 방콕 | 약 2,080 / 2,750 / 3,720 | 편도 | 같은 표기 |
| 3 대륙 간 | 쿠알라룸푸르 / 호놀룰루 / 시드니 | 약 4,600 / 7,330 / 8,320 | 편도 | 같은 표기 |
| 3 대륙 간 | 런던 / 파리 / LA / 뉴욕 / 산티아고 | 약 8,860 / 8,960 / 9,600 / 11,050 / 18,300 | 편도 | 같은 표기 |
| 3 대륙 간 | 지구 둘레 1바퀴 | 40,075 | 누적 | "지구 n바퀴째 도는 중!" |
| 4 크루 합산 | 지구 2바퀴 / 10만 km | 80,150 / 100,000 | 누적 | "지구 n바퀴째 도는 중!" |
| 4 크루 합산 | 20만 km(약 5바퀴) | 200,000 | 누적 | "지구 n바퀴째 도는 중!" |
| 4 크루 합산 | 달나라 진입 | 380,000 | 누적 | "달나라를 향해 달리는 중! (달까지 n%)" |
| 4 크루 합산 | 달까지 / 50만 km | 384,400 / 500,000 | 누적 | "달에서 돌아오는 중 (n%)" |
| 4 크루 합산 | 달 왕복 / 100만 km | 768,800 / 1,000,000 | 누적 | "달까지 다녀왔어요! (달 왕복 n회)" **(제안)** |

표기 규칙 (결정 Q-77):
- 누적 거리로 가장 최근에 넘은 랜드마크의 표기를 쓴다. 그래서 900~1,000km(베이징 약 950km 전후)에도 표기가 비지 않는다.
- 구간별 표기(사용자 가이드): 900km 이하 "서울에서 ○○까지 달렸어요! (왕복 n회)", 약 950~40,000km "서울에서 ○○까지 달렸어요!", 40,075~380,000km 미만 "지구 n바퀴째 도는 중!", 380,000km부터 "달나라를 향해 달리는 중! (달까지 n%)". 20만 km는 지구 구간 안의 기념점이라 "지구 n바퀴째 도는 중!"을 쓴다.
- 아직 넘은 랜드마크가 없으면(60km 미만) "서울–인천 왕복까지 n%"를 보인다. n = 누적 거리 ÷ 60 × 100 **(제안)**이며 소수 첫째 자리까지 보이고 둘째 자리 아래는 버린다(59.999km는 99.9%) (v0.9 추가, test.md TC-1017).
- "달까지 n%"의 n = 누적 거리 ÷ 384,400 × 100이다. "달에서 돌아오는 중 (n%)"의 n = (누적 거리 − 384,400) ÷ 384,400 × 100이며 달 왕복(768,800km)에서 100%가 된다.
- 모든 백분율 n은 자료사전 "률"대로 소수 첫째 자리까지 보이고, 도달 전에 100.0%가 보이지 않도록 소수 둘째 자리 아래를 버린다(59.99km는 99.9%, 380,000km는 달까지 98.8%, 384,399.99km는 달까지 99.9%, 달 도달 직후는 0.0%) (v0.9 추가, test.md TC-1012, TC-3256, TC-3362).
- "지구 n바퀴째"의 n = ⌊누적 ÷ 40,075km⌋ + 1(지금 돌고 있는 바퀴)이다. 40,075km 정각이면 2바퀴째, 360,675km는 10바퀴째, 461,280km는 12바퀴째다. "왕복 n회"의 n = ⌊누적 ÷ 그 랜드마크의 거리⌋이다(서울–인천 60km에서 1회) (v0.9 추가, test.md TC-1008, TC-1018, TC-3254, TC-3258).
- 개인 단계(1~3단계)에 해당하는 랜드마크가 없는 목록이면 개인 랜드마크 표기를 보이지 않는다(FR-077에서 크루가 없을 때 표시하지 않는 것과 같은 처리) (v0.9 추가, test.md TC-1014).
- 개인(FR-051)은 1~3단계, 크루(FR-077)는 4단계까지 쓴다.
- **(제안)** 표시 문구 2개(첫 랜드마크 전, 달 왕복 뒤)는 결정에 문구가 없어 분석 담당이 같은 규칙으로 채운 것이다. 운영 기준값이라 FR을 바꾸지 않고 고칠 수 있다.
