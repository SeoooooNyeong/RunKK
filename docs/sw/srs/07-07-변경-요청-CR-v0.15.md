#### 7.13.11 화면 확인 후속 결정 반영 변경 요청 (2026-10-31, v0.15)

출처: 사용자 결정 D81~D101(`runkk-work/figma-1029/decisions-1029.md` "2026-10-30 후속 결정" 표의 D81 이후, 피그마 재대조 `figma-rediff-1030.md`)과 D102~D127("2026-10-30~31 후속 결정" 표, 화면 확인 중 사용자 요청). v0.14는 같은 표의 D66~D80만 반영했으므로 D81~D127 47건을 이 절에서 처리한다. 승인자: 사용자(대화 결정, 2026-10-30~31). 구현 사실은 코드 저장소 S15P31A207-fig의 작업 트리(커밋하지 않은 변경 포함)를 2026-10-31에 읽어서만 확인했다(아래 "구현 대조").

처리 원칙: 요구(입력·처리·출력·규칙)가 바뀐 결정은 CR-59~CR-74로 FR·NFR을 고쳤다. 화면 문구·배치·색·그림만 바뀐 결정은 CR-75~CR-77에 "표시 변경, FR 영향 없음"으로 남기고 FR을 만들지 않았다. 번호는 다시 매기지 않았고 삭제한 요구는 없다.
