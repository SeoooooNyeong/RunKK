# Wear OS 자유런 GPS 보정 후속

> 작성: 2026-11-13 | 버전: 다음 판 변경 | 입력: S15P31A207-304, FR-032~FR-036·FR-245·FR-248·FR-256, D-368, D-382

## 수정 보수 범위

[임시:CR-박-1] 워치 단독 자유런의 첫 GPS 대기, 잠금 중 위치 전달 지연, 정지·손목 흔들기 때 거리 증가를 다룬다. 기존 폰의 위치 필터는 같은 입력을 기존 단일 표본 경로로 처리한다. 운영 버전에 진단 전용 화면은 포함하지 않는다.

## 구현과 설계 검토

- 워치 준비 화면과 운동이 Health Services의 콜백을 공유한다. 시작 전 준비를 운동까지 유지하고, 인계되지 않은 준비는 화면이 닫히면 정리한다.
- 좌표 묶음을 측정 시각순으로 처리한다. 워치 자유런 종료는 사용자가 종료를 누른 시각까지의 좌표 묶음을 최대 3초 기다린 뒤 확정한다.
- GPS 시각의 IMU와 가까운 GNSS 속도·정확도를 사용한다. 별도 GPS 속도 구독은 워치 자유런에서만 사용하며 일시정지·종료에 맞춰 내린다. 손목 움직임만으로 저속 구간의 위치 밀림을 누적하지 않는다. 이동이 확인되면 후보 위치를 순서대로 기존 칼만 필터에 전달한다.
- 참조 [차량용 GPS·IMU EKF](https://github.com/Janudis/Extended-Kalman-Filter-GPS_IMU)는 차량의 전진 속도와 요 각속도를 전제로 한다. 손목 자이로의 회전을 러너의 진행 방향으로 쓰면 정지 중 손목 움직임을 이동으로 추정할 수 있다. 방향 또는 원시 IMU가 없는 기존 워치 기록으로 차량 모델의 적합성을 확인할 수 없어 기존 위치·속도 칼만 필터를 유지한다.
- GPS가 늦게 도착한 경우에는 실제 위치를 사용한다. 측정 표본이 없는 구간을 가속도 적분으로 채우지 않는다. 0.65m/s 부근의 느린 보행과 기기별 배터리 비용은 실기기에서 확인한다.
