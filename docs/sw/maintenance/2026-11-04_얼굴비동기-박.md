# 얼굴 비동기 계약 변경 요청

> 작성: 2026-11-04 | 버전: 다음 판 변경 | 입력: Jira S15P31A207-276, 사용자 변경 통보와 비동기 계약 승인, develop 15479cf2, ai/tests/contract/faces-*.json

## 접수와 분류

- 요청자는 백엔드 담당 사용자다. 2차 배포 전에 셀카 연결을 복구한다.
- 원문은 “옛 POST /faces는 ai에서 없어졌습니다”다.
- 현재 AiServerFaceGateway는 삭제된 경로를 호출하고 생성 실패로 처리한다.
- 외부 시스템 변경에 따른 적응 보수다. 앱 공개 계약과 이미지 표현도 바뀌므로 해당 부분은 요구·설계 변경으로 추적한다.
- 변경 요청은 [임시:CR-박-얼굴1]이다. 사용자 승인 범위는 비동기 백엔드 API와 3레이어 전달, 기존 데이터 조회 유지다.

## 수정 계획

1. 접수는 회원 인증 속성으로 정한 ID를 AI에 전달한다. 셀카 원본은 저장하지 않는다.
2. 앱은 작업을 폴링한다. 각 AI 호출은 기존 읽기 제한 15초를 사용한다.
3. 작업 상태·요청 해시·반영 여부를 저장한다. 외부 호출 중에는 DB 행 잠금을 유지하지 않는다.
4. 동일 이미지의 재전송은 기존 작업을 반환한다. 성공 결과는 한 번만 생성 횟수에 반영한다.
5. 생성 결과는 Node의 3레이어와 합성 메타데이터를 사용한다. 기존 얼굴 데이터는 조회를 지원한다.
6. Node의 얼굴 삭제는 제공되지 않아 #257·#244의 미해결 사항으로 남긴다.

## 시험과 상태

- 새 계약 시험을 먼저 추가했고 미구현 클래스 때문에 compileTestJava가 실패했다.
- 실제 Node 과금 호출과 운영 환경변수 변경은 로컬 계약 시험과 별도로 기록한다.
- 구현·자동 검증을 마쳤다. MR 사람 검토와 실제 Node·앱 시스템 시험은 대기 상태다.
