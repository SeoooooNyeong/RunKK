### 1.1 요청 원문 (2026-11-14)

사용자가 붙여 넣은 수정 요청 14건 가운데 이번 범위에 든 것(번호는 피그마 시안 행 번호):

| 번호 | 원문 요지 |
|------|-----------|
| ① | 길드(크루)에 아바타 프로필이 나와야 한다 |

| ③ | 대결런에 상대 아바타가 보여야 한다 |

### 1.3 측정 가능한 문장으로 다시 쓰기

| 번호 | 재정의 (완료 조건) |
|------|--------------------|
| ①-가 | 크루원 목록 줄과 크루원 정보 팝업의 원에 그 크루원의 아바타 얼굴이 보인다. 얼굴이 없는 크루원은 성별 기본 얼굴이다 |
| ①-나 | 크루 채팅의 메시지 줄과 반응자 목록의 원에 작성자의 아바타 얼굴이 보인다 |
| ② | 기록런 셀프런 고르기 화면에서 거리를 고르기 전에는 상대 자리가 물음표다. 거리를 고르면 그 기록을 세운 날의 내 아바타(의상, 체형, 러닝량, 얼굴)가 전신으로 보인다. 모습이 저장되지 않은 기록은 지금 모습이다. 셀럽런은 고르기 전 물음표만 적용한다 |
| ③-가 | 대결 진행 화면에 트랙 보기가 있다: 진행 막대(전체 거리, 나와 상대 점), 두 레인의 달리는 아바타(나와 상대), 이름표, 거리 자. 차이가 화면 폭(약 30 m)을 넘으면 상대를 가장자리 칩으로 보이고, 남은 거리가 30 m 이내면 결승선이 보인다. 상대 아바타는 상대의 실제 얼굴과 의상이다(배치고사 상대는 물음표) |
| ③-나 | 트랙 카드 왼쪽 위 「트랙 \| 지도」로 보기를 바꾼다. 고른 보기는 다음 대결에도 유지된다. 지도 보기는 지도에 나만 그리고(달린 길 실선, 지금 위치), 상대는 진행 막대의 점과 아래 문장으로만 보인다 |
| ③-다 | 크루런 진행 화면에도 트랙 보기와 전환이 있다. 아래 레인은 나, 위 레인은 나와 가장 가까운 크루원 한 명이고 나머지는 가장자리 칩(앞 n명, 뒤 n명)으로 묶는다. 진행 막대에 참가 크루원을 모두 점으로 찍고 아래에 내 순위와 참가 인원을 보인다 |
| ③-라 | 자유런 측정 화면은 전환 없이 지도 한 장에 달린 길과 내 위치만 보인다 |
| ④ | 매칭 대기 화면에서 뒤로 가기를 누르면 확인 창이 뜬다(「나가기」, 「계속 기다리기」, 기본은 계속 기다리기). 대기 화면 아래에 「화면을 나가면 매칭이 취소돼요」가 항상 보인다 |
| ⑤ | 자유런과 크루런 결과 화면 위쪽에 얼굴 원 대신 무대 배경과 서 있는 전신 아바타가 보인다. 배치는 U-7 수치다 |
| ⑥ | 기록 카드 앞면과 공유 그림에 내 아바타 전신이 보이고 그림 칸이 카드 높이의 약 60%다 |
| ⑦ | 처음 홈에 들어가면 시작 카드(「둘러보기」, 「건너뛰기」)가 뜨고, 둘러보기를 누르면 4단계(자유런, 배틀런, 기록런, 내 러너) 안내가 차례로 나온다. 설정에 「가이드 다시 보기」가 있다 |
| ⑧ | 크루 정보에서 「크루원 초대」를 누르면 초대 창이 뜬다: 초대 코드와 만료일, 「복사」, 「카카오톡으로 보내기」, 「초대 링크 복사」, 「다른 앱으로 공유」. 카카오톡 메시지의 버튼을 누르면 앱이 열려 그 크루의 가입 확인 화면으로 간다 |
