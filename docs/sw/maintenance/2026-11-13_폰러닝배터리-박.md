# 폰 자유런 배터리 최적화 설정 안내

> 작성: 2026-11-13 | 버전: srs v0.32, test v0.27에 반영(2026-11-14 병합) | 입력: S15P31A207-305, FR-032·FR-034·FR-035, D-267

## 수정 요청과 범위

CR-211 화면 잠금 중 발생한 자유런 거리 누락을 조사하고, 폰 앱에서 OS 배터리 제한을 사용자가 확인·해제할 수 있게 한다. 개발 서버의 해당 기록에는 76초 위치 공백과 65.1m 직선 제외 구간이 있었다. 서버에는 원본 위치 콜백이 없어 절전과 앱 필터 중 원인을 확정할 수 없다.

## 동작

- 기존 자유런 위치 수집 동의를 확인한 뒤, 앱이 최적화 예외 상태가 아니면 홈 진입 흐름당 한 번 안내한다.
- 사용자가 설정 열기를 선택하면 Android 배터리 최적화 설정을 연다. 기기가 해당 화면을 제공하지 않으면 런크크 앱 정보로 연결한다. 설정 뒤 홈에 돌아와 자유런을 다시 누르면 된다.
- 지금 시작을 누르면 기존 위치 권한 흐름으로 진행한다. 두 설정을 모두 열 수 없어도 동일하게 진행한다. 뒤로가기는 안내만 닫는다.
- Google Play의 직접 면제 요청 권한 없이 시스템 설정에서 사용자가 선택한다. 기기 전체 절전 상태는 OS와 사용자의 설정을 따른다.
- 워치 및 거리 보정 알고리즘은 작업 범위 밖이다. 휴대폰 표시 버전은 0.11.7이며 Play 코드 증가는 기존 CI 방식을 사용한다.
