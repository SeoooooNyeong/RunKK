Fan-In은 `feature:home`, `feature:battle`, `feature:crew`다. 모두 기존 `core:ui` 의존을 사용한다. ViewModel, 서버 API, DTO, 저장 자료와 파생 데이터는 바꾸지 않는다. 기존 설계와 작성 이력이 있어 역공학 대상이 아니다. 이전 `maintenance/2026-11-13_폰러닝배터리-박.md`의 권장 설정을 이번 PM 결정으로 대체한다. 다른 작성자의 조각은 pending으로 변경 요청한다.

## 수정 계획과 예외

1. 조건은 `PowerManager.isPowerSaveMode == true`뿐이다. 앱별 최적화 예외는 읽지 않는다.
2. 설정은 절전 모드 설정 → 배터리 사용량 설정 → 현재 앱 상세 순이다. Activity 없음과 접근 거부만 다음 후보로 넘긴다. 모두 열 수 없으면 출발을 이어 간다.
3. 같은 화면에서 안내를 본 상태를 저장해 기존 홈 동작을 유지한다. 「그냥 시작」 뒤에는 다시 묻지 않는다. 뒤로 가기와 바깥 누름은 출발하지 않는다.
4. 설정 화면을 여는 동안 안내를 유지한다. 돌아왔을 때 절전 모드가 꺼졌으면 보류한 동작을 이어 가고, 켜져 있으면 기존 안내에서 선택할 수 있다. 자동 매칭 진입이 멈춘 채 남지 않게 한다.
5. 브랜치 `impl/S15P31A207-306-battery` 유지, 커밋/push/MR 없음. Gradle은 지정 JDK/SDK와 `--project-cache-dir .gradle/bat-cache --max-workers=2`를 쓴다. 다른 작업자의 데몬은 종료하지 않는다.

범위 해석: 배터리 안내에서 금지 표현을 제거한다. 크루런 거리의 기존 「제한 없음」은 배터리와 다른 용어이므로 PM에게 적용 범위를 별도 확인한다.
