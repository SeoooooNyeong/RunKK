## 4. 분할 규칙

- 목차 파일 이름은 원래 이름(`srs.md` 등)을 그대로 쓴다. `sw-*` 스킬이 이 이름으로 산출물을 찾는다. 목차 파일에는 제목, 작성 헤더, 문서 상태, 다음 단계와 목차 표가 남는다.
- 본문은 같은 이름의 폴더에 `장-순번-주제.md`로 나눴다. 파일 하나가 60KB를 넘지 않도록 큰 장은 절(###)이나 패키지(####) 단위로 다시 나눴다.
- 장·절 번호는 원래 번호를 그대로 쓴다. 다른 문서가 "srs.md 6.3"처럼 참조하면 목차 표에서 해당 파일을 찾는다.
- 조각 파일의 첫 줄은 목차·이전·다음 링크다. 본문을 고칠 때는 조각 파일을 고치고, 버전은 목차 파일 헤더에서 올린다.
- estimate.md(91KB), decisions.md는 100KB 아래라 나누지 않았다. schedule.md는 2026-11-02 v0.8에서 100KB를 넘어 schedule/ 조각으로 나눴다(v0.12 기준 8개). 2026-11-08에 60KB를 넘던 조각 셋을 다시 나눴다: design-oo/06-06(168KB → 06-06~06-06e), srs/07-01(→ 07-01b), srs/06-04(→ 06-04b). 다른 문서의 링크가 깨지지 않도록 원래 이름을 첫 조각으로 남겼다. 같은 날 100KB를 넘던 이력 조각 12개(test 7, design-oo 3, code-review 2)도 같은 방식으로 나눴다. 이제 100KB를 넘는 조각은 없고, 60KB~100KB 조각은 남아 있다.
