#### 4.1 설계·코드 계약 차이 9건 판정

API 계약 v1.0 승인 기록(2026-10-23 팀 위키, 이 검토에서는 열지 않고 사용자가 전한 목록을 썼다)의 9건이다. 코드는 MR !14 e0b360fb에서 확인했다. 앱과 서버는 양쪽 모두 코드 쪽 형식으로 맞춰져 있고 계약 시험이 그것을 고정하므로, 9건 모두 "설계서가 낡았거나 설계를 따르지 않은" 차이이지 앱·서버 사이의 동작 결함이 아니다. 그래서 치명(설계 기준선과 다른 인터페이스)으로 보지 않았다. 설계서(design-oo v0.11)는 기준선(v1.0) 전이고, 계약 v1.0은 이 차이를 알고 승인했다.
