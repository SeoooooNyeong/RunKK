## 4. 릴리스 점검: 출시 노트 문구 규칙 (Jira 315)

Play 출시 노트(콘솔에 손으로 쓴다)는 사용자가 무엇을 경험하는지만 쓴다. CI의 `--release-notes`(Firebase 배포용 내부 문구)는 대상이 아니다.

| 규칙 | 하지 않는다 | 한다 |
|------|-------------|------|
| 1. 세부 규칙의 숫자·조건을 쓰지 않는다 | 「모두 준비하면 3초 뒤 자동 출발」, 「30초 안에 다시 열면」 | 「크루원이 모두 준비하면 바로 출발해요」 |
| 2. 내부 이름·기술 용어를 쓰지 않는다 | 「gzip」, 「ETag」, 「캐시」, 「edge-to-edge」 | 「기록을 더 빠르게 올려요」, 「화면 끝까지 시원하게 보여요」 |
| 3. 고친 문제는 사용자가 겪은 모습으로 쓴다 | 「myRun 필드 추가」 | 「달리기를 끝낸 뒤에는 크루런 탭에서 바로 결과를 볼 수 있어요」 |
| 4. 한 줄에 한 가지, 다섯 줄 이내 | 긴 문단 | 짧은 목록 |
| 5. 약속처럼 읽히는 수치를 쓰지 않는다 | 「아바타가 1초 안에 떠요」 | 「아바타가 더 빨리 떠요」 |

v0.14 출시 노트 초안(규칙 적용, Codex 문구 다듬기 대상):

- 아바타와 얼굴이 더 빨리 떠요.
- 달리기를 끝낸 뒤 크루런 탭에서 바로 결과를 볼 수 있어요.
- 기록 상세에서 그 러닝의 런바디 분석으로 바로 갈 수 있어요.
- 티어 재평가 화면이 새로워졌어요.
- 아바타 목과 옷이 더 자연스럽게 이어져요.
