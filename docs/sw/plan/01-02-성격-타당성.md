혼자 뛰면 심심하고 같이 뛰기엔 부담스러운 러너를 위해, 비대면 경쟁·Runimal·크루로 "느슨한 유대감"을 제공하는 Android 러닝 앱이다. 핵심 가치는 "함께 뛰지만 만나지 않는다"이다.

### 2.3 범위 재정의 트리거 (타당성 5장)

다음 조건이 발생하면 해당 범위를 재정의한다.

1. 1단계 실측에서 1km 오차가 10%를 넘고 필터링으로도 개선되지 않으면 거리 기준 기능(나와의 싸움·레이스·랭킹)을 시간 기준으로 재설계한다. 10/17 스파이크는 5% 이내로 통과했으므로 1단계 실측(2.10)에서 다시 확인한다.
2. 11/02에 위치 기반 트래킹과 크루 기본 기능이 실기기에서 동작하지 않으면 1단계 미완료 기능을 2단계 첫 주에 끝내고 2단계 기능은 화면 수를 최소로 줄여 11/13 동결을 지킨다.
3. 모바일 경험자가 없고 2주차 말까지 위치 기반 기록이 동작하지 않으면 범위를 트래킹·기록·크루·레이스로 축소하고 매칭·Runimal을 2차로 넘긴다.
4. LLM 제공사 약관상 비식별 요건을 충족할 수 없으면 AI 코멘트를 규칙 기반 문구로 대체한다.
5. WebSocket 구현이나 안정성 확보가 일정 안에 어려우면 랜덤 대결의 진행도 교환을 짧은 주기의 REST 폴링으로 대체한다(2026-10-18 정책).

원본 트리거 중 "컨설턴트가 위치기반서비스사업 신고가 필요하다고 판단할 때"는 2026-10-18 확인으로 해소되어 뺐다.
