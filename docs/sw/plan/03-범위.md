## 3. 범위

### 3.1 기능

포함 범위의 모든 기능은 Must다(2026-10-15 결정). 단계는 1단계(10/19~11/02, 1차 배포)와 2단계(11/03~11/13, 기능 동결)다.
핵심 기능 7종은 기획안 3.1 목표 문장을 기준으로 한다(2026-10-18 결정): ① 위치 기반 러닝 기록, ② 랜덤 매칭 1:1 비대면 경쟁, ③ 나와의 싸움, ④ 유명인과 경쟁, ⑤ 온라인 크루 비동기 협동 레이스, ⑥ Runimal, ⑦ 러닝 성향에 맞는 크루 추천.
(v0.28 변경) ⑦은 "성향 태그로 크루 찾기"로 바꾼다. 크루 추천은 하지 않고, 크루장이 크루의 성향 태그를 고르고 러너가 성향 태그를 골라 크루를 찾는다(2026-11-01 사용자 결정 A3, 부록 G). 기획안 3.1 목표 문장도 바꿔야 한다(2.4 외부 문서 갱신 대상).

**1차 배포와 2차 배포 구분 (v0.24 변경, srs.md v0.13 7.13.9 CR-24, v0.24, 2026-10-29 위임 결정).** "1차 배포"는 첫 정식 출시다. 위 1단계·2단계(개발 단계)와 따로 쓴다. 아래 표의 기능은 범위에서 지우지 않고 **(2차 배포)** 로 표시하며, 1차 배포 앱은 이 기능의 진입점을 잠그거나 숨긴다(srs.md FR-223, 잠금 아이콘을 누르면 "추후 추가 예정" 안내). 표시가 없는 기능은 1차 배포 대상이다. (v0.30) 1차 배포는 v0.10.0(10/31)으로 끝났고, 2차 배포는 11/13이다(2026-11-02 사용자 확인).

### 3.1.1 비상 시 축소 대상 (2026-10-18 결정)

비상 계획이 실행될 때 대체 경로로 낮출 수 있는 기능은 아래 두 가지뿐이다. 나머지 기능은 축소하지 않고 Must로 완성한다.
요구사항 명세서 v0.1의 "P1 = 일정 압박 시 축소 가능"도 이 두 항목으로 한정한다(B-15).

| 순서 | 대상 | 축소 방식 | 근거 |
|------|------|-----------|------|
| 1 | F-11 셀카 아바타 생성 | 기본 캐릭터 선택 경로만 제공 | 원본 R3 예방책 |
| 2 | F-04 AI 코멘트 | 규칙 기반 문구로 대체 | 원본 R4 발생 시 대응 |

- 핵심 기능 7종(①~⑦)은 축소 대상이 아니다.
- (v0.24 변경) 위 대상 1은 1차 배포 앱이 기본 아바타만 쓰므로 1차 배포 기준으로는 이미 적용된 상태에 가깝다(3.1 배포 구분, 확인 필요). 크루(F-06~F-09)를 2차 배포로 미룬 것은 이 비상 축소가 아니라 2026-10-29 범위 결정이다. 표의 두 대상은 바꾸지 않는다.
- 다른 기능의 일정 압박은 원본 범위 버퍼(미완 기능을 화면 1개·규칙 1개의 최소 규칙으로 배포하고 다음 단계에서 보강)와 인력 재배치로 대응한다.
