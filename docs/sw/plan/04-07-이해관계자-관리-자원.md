## 5. 프로젝트 관리 3요소

| 요소 | 내용 |
|------|------|
| 사람(People) | 필요 역할: PM, 백엔드 개발, 안드로이드·Wear OS 개발, AI(이미지 생성 파이프라인·추천 규칙·LLM 연동), 인프라·배포, 테스트(전원 공동). 팀 인원 6명은 SSAFY 편성으로 정해진 제약이며 역할은 2026-10-16 확정했다(7절). 2026-10-28 이정현이 빠져 5명이 됐고, 이정현의 남은 업무는 이성현이 인수했다(D-08). 6명 × 7주가 산정 노력에 충분한지는 `sw-estimate`에서 검증한다 |

| 프로세스(Process) | 생명주기 모형: 점진적 개발(증분 모형)에 1주 스프린트를 결합한다(2026-10-18 결정). 1차(v0.9)·2차(v0.95)·최종(v1.0)이 증분 단위다. 운영 방식은 1주 스프린트(월요일 계획, 금요일 시연 리뷰), 데일리 스크럼 10분이다. 업무 흐름은 Jira 이슈(스토리 → 서브태스크) 기준 지시·추적, 기능 브랜치 → MR → 담당 영역 밖 1명 이상 리뷰 승인 → develop 병합이다. 완료 기준은 기능 동작, 테스트 통과, 리뷰 승인, 실기기 확인을 모두 만족하는 것이다 |
