- **최종 마감이 성립하지 않는다.**
  - 임계 경로는 7.66주로 가용 7.14주를 0.52주 넘는다. 예비를 넣을 공간도 없다.
  - estimate.md v0.2에 따라 11/23부터 평일 전일(주 5 인일)로 계산한 결과다.
- **주 80시간을 12/01까지 이어가면** 최종 배포는 11/30, 전시 준비는 11/30에 끝난다.
  - 이 경우 전시 마감은 0.11주(약 하루) 여유로 통과한다.
  - 그래도 기능 동결은 11/26이고, 본선은 동결 전 빌드로 치른다(4.1).
  - 이 근무 연장은 estimate.md A-3과 다르다. 그래서 팀 결정이 필요하다(10절).
- **임계 경로는 박재영 연쇄로 바뀌었다.**
  - 경로: 데이터 모델 → 백엔드 C → 앱 B → 백엔드 E → 워치 동기화 → 크루런 앱 → 2단계 통합 테스트 → 동결 → 버그 수정 → 최종 배포
  - 박재영 몫이 56.3 인일(실행 활동)이라 1인 주 80시간으로도 11/26에야 개발이 끝난다.
  - 이정현(55.3 인일)은 11/24, 오규연(개발 48.1 + 발표자료 6 + 전시 자료 3)은 11/21에 개발이 끝난다.
- **세 개발자의 실행 구간(10/19~11/13) 부하는 136%다.** v0.4의 101%에서 다시 올랐다. 반면 서동혁·안선영·이성현은 W3~W8에 주 0~61시간으로 여유가 크다(6절).
