## 12. v0.8 재일정: ai 연결을 더한 11/13 기능 동결 판정 (v0.8 변경, 이력: 현재 기준은 13절)

입력은 estimate.md v0.4 11절(ai 연결 44.0 인일 중 동결 전 40.4, 1차 배포 남은 일 21.3 인일 중 동결 전 7.2, 동결 전 합계 47.6 / 가용 100.3 인일)과 plan.md v0.28(A9: 2차 배포 기능도 11/13 동결 전에 구현하고 잠금, R-058 우선순위 런바디 분석 → 파기 연결 → 코치 → 모델 관리 화면)이다. 착수는 2026-11-02(월) 0시 = t 3.00이다(S-10의 t축). 사용자 요청 "최대한 빠르게"에 따라 질문 없이 기본값을 정하고 "(2026-11-02 위임 결정)"으로 표시했다. 11절은 이력이다.

- **판정: ai 연결을 넣어도 11/13 동결 안에 들어간다.** 11절(계수 0.42를 넘으면 불통과)보다 여유가 크다. 1차 배포의 남은 일 대부분이 실적으로 끝났기 때문이다(estimate.md A-23).
- **계수 민감도.** 계수 0.5면 동결 11/11, 계획 방식 그대로(1.0)면 11/14다. 11/14는 허용 지연(11/16) 안이다. 손익분기 계수는 **0.90**이다(12.7).
- **임계 경로(1.09주, 11/02 ~ 11/09).** 요구사항 v0.20(이성현) → 설계서(이성현) → api ai 연결(박재영) → api ↔ ai 계약 시험(안선영) → 기능 동결. 동결 뒤에는 테스트 실행(안선영) → SQA(안선영) → 1차 배포 후보(이성현)가 이어진다.
- **바로 할 일.** 오늘 `/sw-srs` v0.20을 시작한다. 요구사항과 설계서 두 활동이 이성현 한 사람의 직렬 작업이고 임계 경로의 앞 절반(0.58주)이다.
- **2차 배포(잠금 해제) 날짜 제안: 11/27(금), 확인 필요.** 12.8에 근거가 있다.

- **주별 투입 인원.** ①~③ 6명, ④~⑥ 2~3명(서동혁·안선영 시험, 이성현 배포). 확정 인원 6명을 넘는 구간이 없고 동결 뒤 인원이 늘지 않는다(Brooks 법칙 통과).
- **사람별 동결 전 부하(기간, 주).** 이성현 0.79(A1·A2·A8·A9·A10), 박재영 0.47, 안선영 0.40, 서동혁 0.22, 이정현 0.21, 오규연 0.18. 가용 1.71주 안이다. 이성현과 박재영이 임계 경로를 쥔다.
- **조직.** 중앙집중형(책임 프로그래머 이성현)과 역할 4개는 7절 그대로다. 요구사항·설계·기술 판단은 이성현이 한다. 보조 프로그래머(안선영)는 테스트 케이스·계약 시험·SQA를 맡고 판단 업무는 맡지 않는다.
