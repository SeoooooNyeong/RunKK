### 1. 설계 일치

**이름·인터페이스 대조.** 5.6.2의 새 클래스는 모두 같은 이름·패키지로 있다: battle.FriendInvite·FriendInviteStatus·FriendInviteRepository·FriendInviteService·FriendInviteQuery·RunnerAvailability·FriendInviteIssue·FriendInviteView·BattleOutcome·RealNameConsent, battle.live.FriendInviteDeclined·FriendInviteExpired, running.RunDeletionService·RunRecordDeleted·RouteShape·RunListRow·RouteShapeBackfillService·RunEvaluationNote·EvaluationView, runimal.RunimalTypeShare·RunimalTypeShareRepository·RunimalTypeService·RunimalTypeCatalog·RunimalTypeDetail, profile.RecentRun, web.battle.FriendInviteController·FriendInviteLinks·FriendInviteDtos, web.record.RecordListAssembler, batch.battle.FriendInviteExpiryJob, batch.runimal.RunimalShareJob·RunimalSchedulingConfig, batch.running.RouteShapeBackfillJob, infra.battle.JpaFriendInviteRepository, infra.runimal.JpaRunimalTypeShareRepository. 설계에 있는데 코드에 없는 클래스는 0개다.
시그니처가 설계와 다른 곳은 7곳이고 모두 코드 쪽이 낫거나 설계가 비어 있던 것이라 갱신 요청으로 넘긴다(U8-1~U8-5): FriendInviteQuery.mine이 FriendInviteView 대신 토큰을 담은 FriendInviteIssue를 돌려줌(링크 복구에 토큰이 필요하다), FriendInviteRepository.saveImmediately 추가, linkBattle을 BattleStartService.startFriend 안에서 부름(ck_friend_invite_accepted 때문), invite의 "바쁨 원인이 자기 초대면 INVITE_ALREADY_PENDING", accept의 고유 제약 충돌 한 번 재실행, RunDeletionService가 ApplicationEventPublisher 대신 DomainEventPublisher를 씀, 444cc783의 응답 필드 3개.

### 4. 객체지향 구현

- 캡슐화: 새 엔티티 필드는 모두 private이다. FriendInvite의 inviterId·token·expiresAt·createdAt은 `updatable = false`이고 상태는 open·accept·decline·cancel·expireIfDue·linkBattle로만 바뀐다. 외부가 필드를 직접 바꾸는 코드 없음. 시험의 forceStatus는 시험 소스에만 있다.
- 생성자: FriendInvite는 private 생성자와 정적 open이 거리 검사·토큰·만료 시각(마이크로초 절사)을 한 번에 정해 생성 직후 유효하다. Battle.friend는 ACCEPTED이고 참가자가 있는 초대만 받는다.
- 다형성: 대결 종류 차이는 BattleType 상수 메소드, 초대 상태별 거부 사유는 FriendInviteStatus 상수 값(18.4 판정 허용). 새 자기 타입 분기는 RunimalType.traits 하나(BE8-10). 보조 리뷰가 지적한 BattleHistoryService의 `getType() == CELEBRITY/SELF`는 이번 diff가 만든 줄이 아니다(기존).
- 절차적 스타일: RunnerAvailability·FriendInviteQuery는 상태 없는 판정·조회 서비스이고 규칙은 엔티티(FriendInvite.refusalFor·statusAt)에 있다.
