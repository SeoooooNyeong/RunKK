### 9. 판정

판정: □ 합격  ■ 조건부  □ 불합격 (치명 0 / 중 2 / 경 14)

근거: 치명 0, 중 2다. 판정표 숫자만 보면 합격 구간(중 3 이하, 설계 일치 점검 수행, 형상 관리 5항목 예)이지만, 이번 반복의 합격 조건은 총괄 지시 "치명·중 0"이다. 중 2건이 모두 필수 요구(FR-276, FR-281) 위반이라 조건부로 둔다. 치명 정의(goto 등가, 내용·공통 결합, 설계에 없는 양방향 의존)와 개인정보 실제 노출 경로는 없다.

단위별: BE 1차 수정 0/0/1, AN 1차 수정 0/0/0, AN-2 0/2/6, 시험 0/0/1, 이월 0/0/6.

합격으로 올리는 조건(3차 확인에서 본다):
1. PL2-A1 고침 + 시험(단위·기준 이미지).
2. PL2-A2 고침 + 시험(정리 중 회복, 진행 읽기 실패).
그러면 중 0이 된다. 경은 판정에 영향이 없으나 PL2-A4·A5·A7(접근성)은 같은 MR에서 함께 고치기를 권한다.
