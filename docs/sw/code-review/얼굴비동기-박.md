## 범위와 기준

avatar, infra.avatar, infra.integration.ai, web.avatar의 변경 파일과 V36을 점검했다. 기존 패키지 경계·짧은 트랜잭션·인증 속성 사용·이미지 로그 금지 기준을 적용했다.

| 발견 항목 | 수정 |
|-----------|------|
| 접수 실패 후 다른 사진 영구 차단 | 만료한 미확정 예약 종료·교체와 회귀 시험 |

## 설계 일치와 형상

이름·포트·상태 전이·의존 방향은 설계 조각과 대응한다. 외부 호출 중 DB 잠금, 원본 사진 저장, 이미지·토큰 로그를 추가하지 않았다. 모든 DB 쿼리는 매개변수를 사용하고 외부 주소는 기존 AiServerClient에서만 얻는다.

서비스의 생성자 주입 인자는 8개다. 기존 DI 방식과 명시적인 책임 경계를 유지한 검토 항목으로 기록한다. 조건이 많은 reserve는 한도·재접수·동시 접수·만료 경로를 우선 시험 대상으로 두었다. 전체 CFG의 세 방법 계산은 수행하지 않았다.

수정 항목은 자동·수동 코드 검토 뒤 회귀 시험에 포함한다. 사람 승인과 실제 Node·앱 시스템 시험 전까지 배포 판정은 조건부다.
