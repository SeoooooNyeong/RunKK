goto 등가물(라벨 break·continue, 예외로 정상 흐름 분기, switch fallthrough): 없음. cancel의 종류 거부는 사유 코드 예외로 요청을 끝내는 것이고 흐름 분기가 아니다. ### 4. 객체지향 구현

- 캡슐화: 새 필드(opponentGender, opponentFigure, shownGender, figureKey)는 모두 private이다. opponentFigure·figureKey는 생성 때만 정하고(`updatable = false`, 생성자), 성별은 showOpponentAs·showMemberAs(→ 패키지 전용 showAs)로만 한 번 바뀐다. 외부가 필드를 직접 바꾸는 코드 없음.
- 다형성: 취소 허용은 BattleType 상수 메소드 allowsCancel(cancelsOnForfeit를 대신함)로 두어 종류 if를 늘리지 않았다. 셀럽 그림 키는 OpponentRecord의 default 메소드 figureKey()를 CelebrityRecord만 재정의한다(가상·러너 기록은 빈 값). GhostMatcher가 상대 종류를 묻지 않는 13.1 예를 지킨다.
- 정보 은닉: OpponentGenders는 패키지 전용 final 유틸리티이고 응답 계층에는 문자열만 낸다(D-314). member.Gender가 battle.live·web.battle로 새지 않는다.
- 생성자: 시험 편의 겹치기 생성자 3개(BE10-5)가 운영 클래스의 공개 표면을 늘렸다.
