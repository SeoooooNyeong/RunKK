권고:
1. 변경 통제는 사용자 결정이라 이번 리뷰에서 결함으로 고치라고 요구하지 않고 판정 요인으로만 기록한다. 이 항목이 아니오로 남는 동안 판정은 합격이 될 수 없다(합격 조건은 5항목 모두 예).
2. 이후에 Jira를 쓰게 되면 다음 단계(B2·A2)부터 `feature/S15P31A207-NN-작업명` 브랜치와 `[S15P31A207-NN]` 커밋 키를 쓰고, 이미 올린 커밋은 다시 쓰지 않는다.
3. Jira를 쓰지 않는 동안에는 MR 본문에 이 결과서 경로와 설계서 갱신 요청 ID(CR-U01~CR-U41)를 적어 변경 근거를 남긴다(MR !8 본문에 반영).
4. 단계 끝마다 태그를 단다(예: `backend-v0.1.0`, `android-v0.1.0-a1`, `ai-v0.1.0`). AGENTS.md 명령 표에 ai 행을 더하고, 통합 커밋 유형(`merge`)을 유형 목록에 넣거나 `chore`로 쓴다.
