## 범위와 기준

- 대상: WatchFlowViewModel.onCelebritySelected와 새 비공개 목록 보정 함수, 대응 클래스 시험.
- 기준: 매개변수 4개 이하, 중첩 3 이하, 함수 길이 50줄 권고, 복잡도 10 초과는 우선 시험.
- 기존 watch.ui → watch.battle 방향과 불변 WatchFlow 복사 방식을 유지한다.
- 구현 에이전트의 정적 점검 뒤 보안 리뷰 에이전트가 읽기 전용으로 비동기·회귀를 재검토했다. 사람 승인은 별도다.

- 새 함수는 매개변수 2개, 빈 목록 선택 1개, 순환 복잡도 2다.
- 기존 onCelebritySelected는 가드·비동기 분기로 복잡도 10을 넘는 우선 시험 대상이다. 관련 클래스 102건을 재실행했다.
- 삭제·목록 비움·재선택 무시·일시 실패 유지 경로를 직접 단언했다.
