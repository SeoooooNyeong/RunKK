이 조각은 v0.14(2026-10-29) 결정 가운데 안드로이드 앱(폰·워치) 쪽이다. 서버 쪽 D-218~D-249는 [05-06-설계-결정-v0.14-서버](05-06-설계-결정-v0.14-서버.md)에, 서버가 그리는 친구 대결 상태도와 기록 삭제 시퀀스는 [02-03-동적-모델-v0.14](02-03-동적-모델-v0.14.md)에 있다. 입력은 srs.md v0.13 7.13.9(CR-24~CR-51, 새 FR-223~FR-231, 삭제 FR-028·FR-182·FR-195), 디자이너 피그마(화면 64개, 사용자 결정 D01~D65)와 코드 origin/develop 7c42b0fe(android 모듈 app, core, domain, data, feature/\*, wear)다. 사용자가 2026-10-29 "10번까지 너가 전부 알아서 진행하고 MR 올려둬"로 위임해 묻지 않고 기본값으로 정했고, 기본값으로 정한 곳은 결정 칸에 **(기본값)** 을 붙였다.

API 이름과 필드는 서버 조각 [05-06](05-06-설계-결정-v0.14-서버.md) 5.6.3 계약표가 기준이고, v0.14 통합 때 이 조각을 그 계약에 맞췄다. 맞춘 곳은 "(v0.14 통합, 서버 D-xxx에 맞춤)"을 붙였다. 필요한 API 표(옛 9절)와 외부 준비물(옛 10절)은 [05-08-설계-v0.14-API-외부준비](05-08-설계-v0.14-API-외부준비.md)로 옮겼고, 서버 계약에 없던 값은 거기 "앱 요청"에 모았고, 세 건 모두 같은 조각에서 D-291~D-293으로 받아들였다. 이 조각이 대체하는 옛 결정(D-49 잠금 누름, D-93 (6)·D-157 (7) 정지 한도, D-120·D-157 (1)~(3)의 잠금 상태, v0.9 BetaLock의 셀럽런 잠금)은 통합 작업 때 05-02 해당 행 앞에 "v0.14 D-2xx로 대체"를 붙인다. 이 조각은 기존 조각을 고치지 않는다.

1절(화면과 내비게이션)과 3~8절(1차 배포 잠금 목록, 측정 변경 요약, 친구 대결 앱 구성, 첫 사용 가이드, 앱 쪽 핵심 시퀀스, 클래스 목록)은 조각 상한(60KB) 때문에 [05-09-설계-v0.14-앱-세부](05-09-설계-v0.14-앱-세부.md)로 옮겼다. 내용은 그대로다.
