# 5.6 설계 결정 기록 (이어서: D-415~D-433·D-456~D-460, v0.24 설계 검증 23장·13차 리뷰 반영 · v0.25 보정 · v0.25 보정 2)

> [런크크 객체지향 분석·설계서](../design-oo.md) 목차 · 이전: [05-17-설계-결정-v0.23](05-17-설계-결정-v0.23.md) · 다음: [05-19-설계-결정-v0.26](05-19-설계-결정-v0.26.md)

설계 검증 23장은 v0.23을 조건부 합격으로 판정하고 core.model을 세는 기준이 폰과 워치에서 다르다는 점(R75)을 사용자 결정으로 넘겼다. 사용자는 **(가) 기존 기준 유지(W30)** 를 골랐다: core.model을 폰·워치 모두 화살표로 센다. 그러면 watch.ui Fan-Out이 8로 상한을 넘으므로 대결 흐름을 새 패키지 **watch.battle**로 옮겨 watch.ui를 7 이하로 만든다. 같은 판에 R73·R76·M83~M86과 13차 리뷰 U13-1~U13-6을 반영한다.

앱 R4와 서버 R5가 지금 코드를 고치는 중이다. 이 조각은 **구조와 규칙을 정하고**, 정확한 화살표 수와 R4·R5가 정할 세부는 "구현 확인 필요"로 둔다. 05-16·05-17의 문장은 지우지 않고 7절 표로 대체를 밝힌다.

## 4. 0.1·12.4에 적을 기준 (요약)

- **화살표 세기:** core.model을 포함해 모든 패키지 import를 센다(폰·워치 같음, W30). 자기 모듈 리소스 R(:wear `watch.ui.R`, :data `api.core.R`)만 세지 않는다.
