# 5.6 설계 결정 기록 (이어서: D-358~D-364, v0.20 설계 검증 21장·코드 리뷰 11차 반영)

> [런크크 객체지향 분석·설계서](../design-oo.md) 목차 · 이전: [05-14-설계-결정-v0.19](05-14-설계-결정-v0.19.md) · 다음: [05-16-설계-결정-v0.21](05-16-설계-결정-v0.21.md)

이 조각은 설계 검증 21장(v0.19 본문 조건부 합격, 검토 R59·R60)과 코드 리뷰 11차의 설계서 갱신 요청 U11-1~U11-6, 시험 v0.12 발견 TF-V12-01~03을 설계에 옮긴다. 대부분은 커밋 758de88f("리뷰 11차·설계 검토 v0.14·시험 v0.12 지적 반영")가 이미 고쳤으므로 원칙은 v0.19와 같다: **설계서를 코드에 맞추고** 이름은 코드와 글자 그대로 적는다. 코드는 바꾸지 않았다. 서버·REST·실시간 계약은 바뀌지 않았고, 바뀐 곳은 앱의 다섯 패키지(core.designsystem, app, ui.home, ui.me, ui.record)다. **5.1.2 단위 새 화살표 0**(폰 150개, Konsist 허용 표 그대로), 바뀐 것은 core.designsystem 안의 배치다.
