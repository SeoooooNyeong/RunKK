워치 v2 구현(MR !57)과 12차 리뷰·수정 반복(R1 서버, R2 앱)이 끝났다. 구현은 05-16(v0.22)을 따르되 설계가 정하지 않았거나 다르게 정한 곳을 14.4 결정과 리뷰 갱신 요청으로 남겼다. 이 판의 원칙은 v0.19·v0.20과 같다: **코드가 옳고 설계가 낡은 것은 설계서를 코드에 맞춘다.** 이름은 코드 이름을 그대로 쓴다. 코드에서 아직 정하지 못한 것(보류 결함, 요구 해석)은 8절에, srs에 걸리는 것은 9절 "srs 갱신 요청"에 둔다. srs와 design-review는 이 판에서 고치지 않는다.

05-16의 문장은 지우지 않는다. 이 조각의 결정이 05-16의 해당 문장보다 앞선다(표의 "대체·보충" 칸).
