### 4.3 이해관계자 확인과 SRS 보완 요청

**이해관계자 확인은 아직 하지 않았다.** srs.md 7.2의 검토 회의가 열리지 않았기 때문이다. 확인 방법은 다음과 같이 정해 둔다.

| 대상 | 보일 것 | 확인할 질문 |
|------|---------|-------------|
| 싸피 컨설턴트, 팀 전원 | 7장 유스케이스 다이어그램 | 빠진 기능이나 잘못 묶인 액터가 있는가 |
| 팀 전원(특히 백엔드·안드로이드) | SQ-03, SQ-04, SQ-05(랜덤 대결), SQ-09(크루런) | 10/21 API·실시간 메시지 계약과 맞는가 |
| 베타 테스터 2~3명 | SQ-01(측정), SQ-07(나와의 싸움) 흐름을 화면 순서로 설명 | 길게 눌러 종료·자동 저장·카운트다운 흐름이 예상과 맞는가 |
| 팀 전원(백엔드·안드로이드·워치) (v0.11) | SQ-18(게스트), SQ-19(일시정지), SQ-20(근접 알림), SQ-21(채팅), SQ-22(신고) | F.2~F.4 REST·실시간·워치 계약과 맞는가 |
| 컨설턴트 (v0.11) | 7.4 크루 유스케이스, SQ-22·SQ-23 | 2026-10-21 피드백(CR-01~CR-09)의 뜻대로 반영했는가 |
