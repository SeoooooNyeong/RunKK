#### 6.1.16 ai 서버 (Python, FastAPI)

api 컨테이너만 부르는 내부 서비스다. v0.11에서 기능 변경은 없다(크루 추천은 처음부터 api 서버에 있었고 이번에 삭제, AI 코치 챗봇은 보류). CR34-26의 입력 관문 규칙만 반영한다 (v0.11, D-91, CR34-26). 모든 입출력은 Pydantic v2 모델이고 회원 식별 항목을 받지 않는다(NFR-024). 외부 호출(LLM, 얼굴 변환 API)은 모두 비동기이고 SDK 자체 재시도를 끈다. 재시도·대체는 api 쪽이 한다(D-58).
