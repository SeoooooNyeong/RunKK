# 5.6 설계 결정 기록 (이어서: D-290~D-300, v0.14 앱 API·외부 준비물·설계 검증 반영)
> 작성: 2026-10-30 | 버전: v0.15(카드 그림 경로·외부 준비 상태·오류 뜻 갱신, [05-10](05-10-설계-결정-v0.15.md) D-304·D-305·D-308) | 입력: 05-06 서버 조각(D-218~D-249), 05-07 앱 조각(D-250~D-289), 코드 origin/develop 7c42b0fe(backend), android 모듈(domain.battle, data.api)

> [런크크 객체지향 분석·설계서](../design-oo.md) 목차 · 이전: [05-07-설계-결정-v0.14-앱](05-07-설계-결정-v0.14-앱.md) · 다음: [05-09-설계-v0.14-앱-세부](05-09-설계-v0.14-앱-세부.md)

이 조각은 v0.14 통합 작업의 결과다. 앱 조각(05-07)이 서버 조각(05-06)보다 먼저 쓰여 API 이름과 필드가 어긋난 곳을 서버 5.6.3 계약표에 맞춰 고쳤고, 그 표와 외부 준비물(옛 05-07의 9절·10절)을 여기로 옮겼다. 계약을 확정할 권한은 서버 조각에 있다. 앱이 요구했는데 서버에 없는 값은 5절 "앱 요청"에 모았고, 세 건(R-1~R-3) 모두 1절의 D-291~D-293으로 받아들였다. 설계 검증(design-review.md 18장)의 개선안 D-294~D-300도 1절 표에 있다. 서버 조각이 60KB 상한에 닿아 있어 요청 행과 받아들인 결정을 거기에 더하지 않고 이 조각에 쓴다. 2026-10-29 사용자 위임("10번까지 너가 전부 알아서 진행")에 따라 묻지 않고 정했다.

## 2. 동행 축 CardKind 확인 (서버 D-247)

서버는 Runimal 동행 축의 "함께 달린 러닝"을 기록의 cardKind가 BATTLE_RUN이고 battleId가 있는 것으로 센다. 앱 코드(S15P31A207-fig/android 작업 사본)를 확인한 결과 맞는다. 바꿀 것이 없어 새 결정은 더하지 않는다.

| 대결 | 앱이 기록에 붙이는 cardKind | 근거(코드) |
|------|----------------------------|-----------|
| 랜덤 대결 | BATTLE_RUN | BattleRunCoordinator.BattleRun.cardKind의 기본값이 BATTLE_RUN이고, 실시간 시작(BattleStart)은 schedule(track, cardKind = null)이라 바꾸지 않는다 |
| 고스트 대결(랜덤에서 넘어간 것) | BATTLE_RUN | 같은 BattleStart 경로이고 opponentTrack만 받는다. cardKind는 null이라 BATTLE_RUN이 남는다 |
| 친구 대결 | BATTLE_RUN | 친구 대결도 MatchFound·BattleStart 경로(서버 hasLiveRival)라 같은 기본값이다. 05-07 D-274가 새 분기를 만들지 않는다 |
| 셀프런 | SELF_RUN | RecordBattleStart.cardKind(SELF_RUN 또는 CELEB_RUN)를 schedule이 받는다 |
| 셀럽런 | CELEB_RUN | 같다 |

측정 시작 명세(RunStartSpec)는 `cardKind = run.cardKind`와 `battleId = run.battleId`를 함께 싣는다(BattleRunCoordinator.begin). 그래서 서버 RunSampleRow.battleRun(cardKind BATTLE_RUN이고 battleId 있음)이 랜덤·고스트·친구 대결을 모두 참으로 판정한다. 셀프런·셀럽런은 거짓이다. 다만 D-266에 따라 셀프런·셀럽런 포기는 기록을 올리지 않는다.

## 5. 앱 요청 (서버 조각에 없는 값)

앱이 요구한 값 가운데 서버 조각 계약에 없고 앱 계산으로 바꿀 수 없는 것이다. 세 건 모두 받아들였고(D-291~D-293), 서버가 값을 아직 주지 않는 동안(옛 서버, 이미지 파일 준비 전)에는 앱이 마지막 열대로 물러난다(D-289). 앱이 계산할 수 있는 값(가장 빠른 1km 구간 번호, 월 요약, 상대 마커 위치)은 여기 없다.

|------|------|-------------|-----------|------------------------|
