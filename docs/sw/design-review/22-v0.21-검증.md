## 22. v0.21 검증 (워치 v2, 2026-10-31)

이 장은 **design-oo.md v0.21**(05-16 D-365~D-384, 02-06 SQ-43~SQ-48·2.4.25·2.4.26, 12.4 v0.21 문단)을 입력으로 review 0~6단계를 적용한 결과다. v0.21은 srs v0.18(CR-92~CR-102, FR-240~FR-260, NFR-048~NFR-051, 정정 W18·W19 포함)의 워치 단독 러닝을 설계로 옮긴 판이다. v0.20은 21.8에서 이미 확인했으므로 이 장의 대상은 v0.21에서 새로 생기거나 바뀐 모듈·패키지·화살표·클래스다. 서버와 폰 패키지 표는 아래에 적은 화살표 말고는 21장 값 그대로다.

코드는 `S15P31A207-watch` feature/runkk-watch-v2 = develop **6400955a**를 읽기만 해 현재 워치 패키지 import, Hilt 바인딩 위치, ModuleRules(Gradle 모듈 규칙), Konsist 허용 표(app ArchitectureTest)와 대조했다. v0.21은 코드를 바꾸기 전에 쓴 설계이므로, 새 화살표는 설계서 본문(결정 표·2절 모듈 명세·3절 클래스 명세·5절 화살표 표)에서 읽어 낸다. 본문 5절 표에 없는데 3절 클래스의 속성·연산에서 나오는 화살표는 누락 화살표(E33~)로 따로 적는다.

설계 담당이 넘긴 판정 대상은 다섯이다.

1. 새 Gradle 모듈 `:data:phone` 분리의 응집도·결합도와 순환 여부
2. `:wear` → `:domain`·`:data` 의존 방향
3. watch.ui Fan-Out 7(상한)
4. WatchFlowViewModel 협력 객체 9개(분해 필요 여부)
5. wear-contract 경로 4개 추가의 하위 호환(D-97)과 구조 시험(ModuleRules·Konsist)에 넣을 항목

### 22.0 입력 정리

**검증 기준.** 0.1 기본값 그대로다: 결합도 상한 스탬프(제어는 검토, 외부·공통·내용은 불허), 응집도 하한 통신적, 패키지 Fan-Out 상한 7, 순환 0, 계층 역행 0. 클래스 협력 객체(생성자로 받는 협력 객체, Clock 제외)는 21장 6항의 관찰 기준 7을 쓰고, 넘으면 검토로 둔다(패키지 기준이 아니므로 불허로 올리지 않는다).
