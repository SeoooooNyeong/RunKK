- `local` 플레이버는 평문 통신을 `10.0.2.2`와 `localhost`에만 허용한다. 실기기에서 adb reverse로 붙일 때 `RUNKK_LOCAL_API_URL`을 `127.0.0.1`로 주면 요청이 나가지 않는다.
