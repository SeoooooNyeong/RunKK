확인 중 알게 된 것:

- `local` 플레이버는 평문 통신을 `10.0.2.2`와 `localhost`에만 허용한다. 실기기에서 adb reverse로 붙일 때 `RUNKK_LOCAL_API_URL`을 `127.0.0.1`로 주면 요청이 나가지 않는다.
- `android/local.properties`의 값이 `-P` 속성보다 먼저다(`secretProperty`). 다른 서버로 붙일 빌드는 그 파일이 없는 worktree에서 만든다.
- 자유런은 가속도 센서가 정지로 판단하면 위치를 버린다. 에뮬레이터에서 거리를 쌓으려면 `adb emu geo fix`와 함께 `adb emu sensor set acceleration`을 흔들어야 한다.
