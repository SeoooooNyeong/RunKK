## 2.3 단위 테스트 — ai 서버 (Python)

ai 서버의 단위는 라우터 함수 하나, 서비스 클래스 하나, 변환기·LLM 클라이언트 클래스 하나다. 패키지(runkk_ai.comment, runkk_ai.face)를 통째로 단위로 잡지 않는다. 목적은 계약 경로(상태 코드·reason·시간 제한·크기 상한)에 숨은 오류를 찾는 것이다. 그래서 경계 바깥값, 정의 밖 항목, 시간 초과, 끊긴 스트림을 정상 입력보다 먼저 고른다.

v0.4: design-oo v0.9 반영(2026-10-21). 설계 v0.8이 이 조각의 발견 사항 TF-AI-01(InternalTokenMiddleware)·TF-AI-03(계약 표본 15개)·TF-AI-04(Gateway 401 → UPSTREAM_FAILED)·TF-AI-07(averageScore 0 초과)·TF-AI-08(코멘트 로그 cancelled)을 6.1.13·6.1.16·14장에 반영했고, v0.9 R39가 5.1.2 ai 행을 InternalTokenMiddleware로 고쳤다. 기존 TC 8개를 고치고 TC 9개(TC-1901~TC-1909)를 더했으며 폐기한 TC는 없다. 화이트박스 5개 함수는 ai/ 코드가 18442f7 뒤로 바뀌지 않아 그대로다. api 쪽 AiServerCommentGateway·AiServerFaceGateway는 그 뒤 통합 브랜치에 들어와(B5 통합 d6dd36e) 계약 시험이 생겼으므로 TC-1596~TC-1599의 대응 시험을 채웠다.

v0.5: design-oo v0.10 반영(2026-10-21). 설계 v0.10은 발견 사항 TF-AI-11(허용 목록 정확 일치)을 6.1.16에 반영했다. TC-1905의 기대 결과와 같아 TC 변경은 없고 해소 표시만 했다. 조각 판정은 그대로다.

### 2.3.2 화이트박스: ExternalFaceApi.convert(image)

코드 위치: `ai/runkk_ai/face/transformer.py:68-85` (보조 함수 `_decode_parts` 104-110, `_reason_of` 113-118은 따로 센다)

```python
async def convert(self, image: bytes) -> SdFacePartImages:
    if not self._base_url:                                   # 조건 1
        raise FaceTransformError("UPSTREAM_FAILED")
    try:
        response = await self._client.post(self._base_url, content=image, ...)
    except httpx.TimeoutException as exc:                    # 조건 2
        raise TimeoutError from exc
    except httpx.HTTPError as exc:                           # 조건 3
        raise FaceTransformError("UPSTREAM_FAILED") from exc
    if response.status_code == httpx.codes.OK:               # 조건 4
        return _decode_parts(response)
    if httpx.codes.is_client_error(response.status_code):    # 조건 5
        reason = _reason_of(response)
        if reason in _CLIENT_SIDE_REASONS:                   # 조건 6
            raise FaceTransformError(cast(FaceFailureReason, reason))
    raise FaceTransformError("UPSTREAM_FAILED")
```

### 2.3.3 화이트박스: CommentService.generate(summary)

코드 위치: `ai/runkk_ai/comment/service.py:45-70` (`_reserve_daily_call` 72-81은 블랙박스 TC-1569~TC-1573에서 본다)

```python
async def generate(self, summary: SummaryIn) -> CommentResult:
    async with self._semaphore:
        if not self._reserve_daily_call():                    # 조건 1
            self._log("error", None, None, detail="daily_cap")
            return CommentResult("error")
        prompt = self._prompt_builder.build(summary)
        started = time.perf_counter()
        try:
            reply = await self._llm.complete(prompt)
        except asyncio.CancelledError:                         # 조건 2
            self._log("cancelled", started, None)
            raise
        except TimeoutError:                                   # 조건 3
            self._log("timeout", started, None)
            return CommentResult("timeout")
        except Exception as exc:                               # 조건 4
            self._log("error", started, None, detail=type(exc).__name__)
            return CommentResult("error")
    text = reply.text.strip()
    if not text or len(text) > COMMENT_MAX_CHARS or reply.stop_reason != NORMAL_STOP:   # 조건 5·6·7
        self._log("error", started, reply, detail="invalid_output")
        return CommentResult("error")
    self._log("ok", started, reply)
    return CommentResult("ok", text)
```

async def create(request, service) -> FaceOut | JSONResponse:

### 2.3.10 계약 케이스: ai 응답 표본과 api Gateway 매핑

`ai/tests/contract/*.json` 표본은 15개다(comment 5: 200·401·422·503·504, face 10: 200·401·413·415·422 4종·503·504). 계획(01-계획)과 지시의 13개와 다르다(TF-AI-03). ai 쪽 시험은 같은 표본으로 응답 본문을 한 글자까지 맞추고, api 쪽 Gateway 시험은 같은 표본을 MockWebServer 응답으로 써서 FailureReason·Optional 변환을 본다. api AiServerCommentGateway·AiServerFaceGateway·AiServerClient는 통합 브랜치에 없다(backend에 AiServer\* 0건). 그래서 TC-1596~TC-1599는 미구현 대상의 블랙박스 케이스다.

v0.4: 설계 v0.8 14장 단위(ai 서버) 행이 표본 15개(401 둘 포함)를 계약 시험 목록으로 적었고(TF-AI-03 반영), 6.1.13 Gateway 행이 상태별 변환을 정했다: comment는 200만 Comment, 401·422·503·504·시간 초과·파싱 오류는 Optional.empty이고 401은 오류 로그 1건. face는 422·503·504가 본문 reason, 413 → TOO_LARGE, 415 → UNSUPPORTED_IMAGE, 401 → UPSTREAM_FAILED(오류 로그 1건), 시간 초과 → TIMEOUT이다(CR-U41, TF-AI-04 반영). 그 뒤 통합 브랜치에 B5가 통합되어(d6dd36e) 두 Gateway와 계약 시험(AiServerCommentGatewayContractTest, AiServerFaceGatewayContractTest, 표본 사본 `backend/src/test/resources/contract/ai`)이 생겼다. 대응 시험 열을 그 이름으로 채웠다. face 401의 로그 수준이 설계와 다르다(TF-AI-10).
