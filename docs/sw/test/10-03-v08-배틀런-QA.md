## 11. v0.8 변경 케이스 (SRS v0.12, CR-16~CR-22, 배틀런 QA 후속)

이 장은 2026-10-27 배틀런 QA(대결 17판) 후속 MR !32(S15P31A207-bqa, fix/battle-qa-1027, 8677af41, develop c88cbbab 기준)가 고친 동작과 SRS v0.12 변경 요청 CR-16~CR-22를 덮는 케이스를 모은다. 요구 대응은 CR-16 → FR-094(출발 전 포기 = 취소), CR-17 → FR-093(패배 문구), CR-18 → FR-220(진행 중 대결 복구 안내, 새), CR-19 → FR-221(매칭 성사 화면 그만두기, 새), CR-20 → FR-222(대결 진행 화면 연결 끊김, 새), CR-21 → FR-170(유명인 기록 거리), CR-22 → FR-080(언랭 거절 뒤 재요청 없음)이다. 11.1은 계획 보강, 11.2는 단위 백엔드, 11.3은 단위 안드로이드, 11.4는 통합, 11.5는 검증·시스템, 11.6은 추적 보강과 기존 케이스 영향, 11.7은 조각 판정이다.
