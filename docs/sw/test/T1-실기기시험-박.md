## 대상과 기록 방법

1차 공개 기능의 변경분을 우선 검증한다. 최신 개발 앱에서 시작 화면을 확인한 뒤 한 대로 가능한 러닝과 랭킹을 먼저 실행한다. 매칭과 워치 시험은 필요한 계정과 기기가 준비되면 이어서 실행한다.
결과에는 앱 빌드, 기기, 재현 순서, 실제 결과를 적는다. 배포를 막는 결함은 S15P31A207-286에 연결하고, 결과표는 S15P31A207-285의 입력으로 사용한다.

시험 환경은 develop `1897c1a7`, `0.11.4-dev`(versionCode 10), 갤럭시 SM-G887N(Android 10)이다. 개발 앱 패키지 `com.a207.runkk.dev`를 교체 설치했다.

## 배포 판정에 넘길 내용

실기기에서 실행한 5개 항목은 통과 4건, 부분 확인 1건이다. 관찰한 범위에서 배포를 막는 결함은 발견하지 못했다. 나머지 5개 항목은 미실행이다.

- 자유런 취소의 저장 제외를 실제 이동 거리로 재확인한다.
- 매칭·대결·예열은 통제된 시험 계정과 두 번째 폰이 준비되면 실행한다.
- 동행과 배치고사는 Wear OS 워치와 해당 시험 계정이 준비되면 실행한다.
