### 12.7 폐기·수정한 기존 케이스 (v0.9)

SRS v0.13이 지운 요구 FR-028(가입 때 기록 공개 고지, CR-39)·FR-182(앱 화면 잠금, CR-26)·FR-195(장시간 정지 자동 종료, CR-25)에 대응하던 케이스와, CR-12·CR-13의 "집계 제외"·흐린 점 표시를 CR-38이 취소해 틀려진 케이스에 "폐기(v0.9, CR-xx)" 표시를 달았다. 케이스 번호와 행은 지우지 않았고, 해당 조각의 "결과" 열을 바꿨다(옛 결과가 미실행이 아니면 "옛 결과"로 남겼다). 케이스 전체가 틀린 것은 "폐기", 입력·기대 결과 일부만 틀린 것은 "일부 폐기", 요구 번호만 바뀌고 기대 결과는 유효한 것은 "근거 변경"이다. 이 표시는 6.1 집계와 6.2 추적표를 다시 만들 때 유효 케이스 수에서 뺀다.

#### 12.7.3 기존 케이스 영향 중 이 장에서 표시하지 않은 것

SRS v0.13은 위 요구 말고도 화면 문구와 구성(홈, 배틀런 진입, 측정·카운트다운·결과 화면, 기록 화면, 랭킹, 프로필, 카드, 대결 결과 문구, 셀프런·셀럽런 선택 등)을 많이 바꿨다. 이 변경에 대응하는 새 기대 결과는 12.5.2의 TC-9895~TC-9919와 12.3의 화면 규칙 TC가 기준이다. 옛 케이스(04-01~04-03의 홈·대결 화면 문구, 02-02의 화면 상태 케이스 등) 가운데 새 기대 결과와 충돌하는 것은 실행 전에 "대체" 표시를 달아야 하며 이 판에서는 개별로 식별하지 않았다(TF-V9-14). 식별한 것은 요구를 지운 경우와 표시를 취소한 경우뿐이다. NFR-011(TC-5015)은 측정 조건에 잠금 화면 진행 알림 켬·폰 잠김·일시정지 구간 포함이 더해졌고(srs NFR-011 v0.13), 새 기준은 TC-9958이다. TC-5015의 수치 기입(10/30)은 그대로다.

#### 12.10.5 이번 실행에서 확인하지 못한 것

- 앱 화면 흐름(검증 46개)과 시스템 12개는 한 건도 실행하지 않았다. 에뮬레이터·실기기·Maestro 결과가 없다.
- 시험 이름에 TC 번호를 달지 않은 시험은 대응에서 빠졌다. 미자동화 97개 가운데 실제 시험이 있는 것은 후속에서 번호를 달아 옮긴다.
- 대응은 작성자가 단 번호를 믿은 것이다. 시험 한 개가 여러 TC(예: TC-9291~TC-9298)를 한꺼번에 달았으면 그 TC 모두를 통과로 적었다. 각 TC의 기대 결과와 단언문을 하나씩 대조하지는 않았다.
