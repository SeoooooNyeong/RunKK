### 0.3 통합 전략

- 사용 기반(서버): 1층 값 `RunnerLook`·`Avatar.equippedItems` → 2층 읽기 `JpaAvatarRepository.findAllByMemberIds`·`RedisRunnerLookSnapshotStore` → 3층 조회 `RunnerLookQuery` → 4층 표현 `RecordDtos`·`RankingController`.

- 스레드 기반: T-RL-1 서버 랭킹 조회 → 모습 붙이기, T-RL-2 앱 응답 → 시상대 전신 그림, T-RL-3 앱 4위부터 얼굴 원 받기, T-RL-4 Redis 장애.
