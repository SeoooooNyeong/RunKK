### v0.6 추가 케이스 (SRS v0.10, TC-7001~TC-7153)

SRS v0.10 변경 요청 7.13(CR-01·CR-03·CR-04·CR-06·CR-07·CR-09·CR-10)으로 생긴 신규 FR-194·FR-195·FR-197·FR-198·FR-199·FR-200·FR-203과 바뀐 FR-001·FR-002·FR-003·FR-004·FR-006·FR-007·FR-021·FR-028·FR-034·FR-036·FR-042·FR-047·FR-048·FR-049·FR-051의 수용 케이스다. 기대 결과는 srs v0.10 3장, 2.6(S-01·S-19·S-20), 3.0.4 경계 해석 기준, 7.13.3 반영 명세에서 가져왔다. 사유 코드·HTTP 상태·enum 값처럼 SRS가 이름을 정하지 않은 관찰값은 design-oo F-v0.11 변경 명세의 F.2(REST 계약)·F.2.3(새 사유 코드)·F.5.1(enum)·F.7(D-89~D-114) 이름을 썼고, 설계 검증이 진행 중이라 클래스 이름은 쓰지 않았다. (제안) 값을 경계나 기대 결과로 쓴 칸에는 "(제안 값)"을 달았다. SRS로 기대 결과를 정할 수 없던 칸(TF-VA-32~TF-VA-36)은 SRS v0.10 보완(7.13.5)(2026-10-22)으로 모두 확정했다. 구현 열은 통합 브랜치 18442f7 기준이라 모두 미구현이고 결과는 "미실행(구현 전)"이다. 기준일은 2026-10-22다. 설계 D-142~D-166 확정 뒤 후속 정정으로 새 케이스 22개를 이 절 끝에 이었다(TC-7048~TC-7060, TC-7135~TC-7142, TC-7154).
