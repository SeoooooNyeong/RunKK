## 검증 범위

V36 자체는 H2 PostgreSQL 모드에서 기존 얼굴 행을 남긴 채 실행했다. 운영 PostgreSQL·Node와 실기기 합성·실제 생성 시간·과금은 미실행이다. 전체 시험에서 Docker 의존 시험이 건너뛰어지면 수를 함께 기록한다.
