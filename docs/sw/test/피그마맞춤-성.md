### 9.5 확인 못 한 것

- 셀카 얼굴의 정렬(눈·안경·헤어·이마·귀·목)과 피부톤 변화, 내 러너·꾸미기 적용, 재실행 유지, 셀카 머리 본문 IO: 생성 결과가 적용되지 않았고(DV-9) 다시 할 때 아바타 서버가 내려가 있었다.
- 실제 FCM 푸시(키 없음, MR 병합 뒤 develop 서버에서 확인).
- AI 코치 대화(LLM 키 없음), 런바디 심박·케이던스 축(시드 기록에 센서 값이 없음).

- 잠금 화면에 알림 내용이 바로 뜨는 모양(이 기기 설정이 아이콘만 표시, 알림창으로 대신 봄).
