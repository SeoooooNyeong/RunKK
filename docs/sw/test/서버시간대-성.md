## 2. 판별력 확인 (옛 설정에서 실패하는가)

application.yml에 옛 `hibernate.jdbc.time_zone: Asia/Seoul`을 잠시 되살리고 ServerTimeZoneStorageIntegrationTest만 돌렸다. [임시:TC-성-3](JVM UTC)이 실패했다(DB 문자열이 「2026-11-09 23:29:00」, 운영에서 본 9시간 앞섬과 같음). 확인 뒤 설정을 되돌렸다. 시험 JVM은 build.gradle.kts가 user.timezone을 Asia/Seoul로 두므로, JVM을 UTC로 바꾸는 이 케이스가 없으면 옛 결함을 시험이 잡지 못한다.

## 3. develop 자료 리허설 ([임시:TC-성-13])
